# pixelplustest

Одна адаптивная копия главной страницы https://pixelplus.ru/ для тестового задания.

## Сайт

Адрес GitHub Pages: https://olegprojectssrore.github.io/pixelplustest/main/. Корневой `dist/index.html` исключён из публикации.

Второй вариант: https://olegprojectssrore.github.io/pixelplustest/main/. Его отдельная разметка находится в `dist/main/index.html`, стили варианта — в `dist/assets/main-variant.css`. Номера телефонов в шапке и мобильном меню используют Open Sans SemiBold из UI Kit; всплывающие QR-коды сохранены. Остальные ресурсы общие с основной страницей.

В варианте `/main/` блок AI-консультации перенесён в шапку: заголовок и аудиторское заключение слева, белая кнопка чата и красная кнопка «Эксперт / Искусственный интеллект» справа. На узких экранах блок занимает отдельный ряд под логотипом и телефонами. Под слайдером этот блок не дублируется.

Публикация выполняется из ветки `main` через `.github/workflows/pages.yml` при изменении страницы или настроек публикации. Скрипт `scripts/prepare_pages.py` готовит копию `dist/` в `outputs/github-pages/`, добавляя префикс `/pixelplustest` к адресам локальных ресурсов. Исходный `dist/` остаётся пригодным для локального запуска и размещения в корне домена.

## Запуск

Готовая страница находится в `dist/index.html`. Установка npm-зависимостей не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Для другого порта задайте переменную окружения `PORT`.

## Состав

- `dist/` — готовая страница, локальные изображения, шрифты, стили и скрипты.
- `dist/assets/site.js` — переходы на оригинал и дополнения для доступности.
- `dist/assets/site.css` — исправление переполнения формы на узких экранах.
- `scripts/build_snapshot.py` — подготовка копии из публичной страницы.
- `scripts/capture.mjs` и `scripts/verify.mjs` — снимки и браузерные проверки.
- `asset-manifest.json` — адреса источников ресурсов.
- `.openai/hosting.json` — параметры размещения страницы.

Копия использует исходные HTML, CSS, изображения и компоненты интерфейса Pixel Plus. Дизайн и материалы принадлежат их правообладателям. Это учебная копия, подготовленная 22 октября 2026 года.

Сохранены секции, четыре главных баннера, карусели, мобильное меню, FAQ, вкладки новостей и поля форм. Первый баннер зафиксирован на «Агентство без неожиданностей»: оригинал меняет порядок баннеров.

Под главным слайдером размещён утверждённый адаптивный макет блока AI-бота: белая кнопка чата и красная кнопка голосового разговора. Разметка и стили находятся в `dist/assets/ai-lead.html` и `dist/assets/ai-lead.css`; сборка сохраняет этот блок. На странице `/main/` кнопка «Эксперт» открывает текстовый чат. Внутри активной сессии доступно переключение на голос. Клиент подключён через `site.js`; публичные параметры Worker, Turnstile и голосового SDK находятся в `dist/assets/audit-config.js`. Секреты остаются на сервере.

Все навигационные ссылки и поиск ведут на исходные адреса. Кнопки заказа и отправки форм переводят на https://pixelplus.ru/contact/zakaz/. Копия не отправляет заполненные поля на сервер Pixel Plus. Встроенный рейтинг Яндекса загружается с оригинального адреса. Аналитика и серверные обработчики исходного сайта не подключены.

## Повторная подготовка и проверка

Для подготовки нужны Python, `requests` и `beautifulsoup4`:

```sh
python -X utf8 scripts/build_snapshot.py
```

При первом запуске скрипт сохраняет исходную разметку в игнорируемой папке `.reference/`; следующие запуски используют этот снимок. Готовый `dist/` включён в Git, поэтому для запуска сайта Python не нужен.

Для браузерных проверок используется Playwright и установленный Microsoft Edge. Если Playwright находится вне проекта, переменная `PLAYWRIGHT_MODULE` должна содержать абсолютный путь к установленному пакету.

```sh
node scripts/verify.mjs
node scripts/capture.mjs http://127.0.0.1:4173 .artifacts
```

Проверки охватывают ширины 360, 390, 768, 1440 и 1920 px; ссылки, ресурсы, горизонтальную прокрутку, JavaScript, меню, главный слайдер, FAQ и вкладки новостей. Результаты и снимки сохраняются в игнорируемой папке `.artifacts/`.

Папка `Тестовое Пиксель Плюс` исключена из Git согласно заданию.


Окно эксперта использует существующий клиент аудита (`audit-client.js`, `audit-http.js`) и отдельное представление (`audit-ui.js`, `audit-ui.css`). На компьютере это светлая панель справа внизу, на экране до 600 px — полноэкранный диалог. Варианты ответа и история прокручиваются отдельно от поля ввода; закрытие не завершает опрос. Оформление использует компоненты UI Kit, красный акцент и Ubuntu существующей страницы.

Переписка и голос подключены к `https://pixelplus-ai.rudiskiyoleg.workers.dev`: клиентский `publicSessionsEnabled` и серверный `PUBLIC_SESSIONS_ENABLED` включены по запросу владельца. Создание сессии и запуск голоса проходят Turnstile; для голоса браузеру нужен доступ к микрофону. DeepSeek и Ultravox вызываются сервером, ключи хранятся в Cloudflare secrets. Используется утверждённая библиотека (`ALLOW_DRAFT_LIBRARY=false`). Независимая оценка точности и полная приёмка реальных аудиоинтервью ещё не завершены; включение интеграции не меняет эти результаты в манифесте библиотеки. Действуют существующие серверные лимиты использования.

При недоступности сервера интерфейс сохраняет явный статус ошибки. После явного отказа создания повтор получает новый Turnstile-токен; при неизвестном сетевом исходе сохраняется исходная операция. Серверный код, миграции и команды проверки находятся в [worker/README.md](worker/README.md).

Проверки интерфейса без обращений к провайдерам:

```powershell
node --test dist/assets/audit-client.test.mjs dist/assets/audit-http.test.mjs dist/assets/audit-turnstile.test.mjs dist/assets/audit-voice.test.mjs
node dist/assets/audit-browser.test.mjs
node scripts/test-expert-panel.mjs
```

Браузерные проверки используют установленный Playwright (путь к ESM задаётся через `PIXELPLUS_PLAYWRIGHT_MODULE`) и Edge. `test-expert-panel.mjs` проверяет настоящую страницу `/main/` с подменой ответов API: четыре размера экрана, запуск чата без звонка, выбор ответа, неподвижное поле ввода, черновик, повторное открытие и состояние PDF. Тестовые файлы не входят в публикацию GitHub Pages.

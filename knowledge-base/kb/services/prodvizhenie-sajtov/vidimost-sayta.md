# Оценка видимости сайта по списку запросов

## Входные данные

На входе предоставляется файл в формате ***.csv**, в котором по колонкам разбиты следующие данные:

- Первая колонка — список поисковых запросов.
- Вторая колонка — позиция сайта по запросу в поисковой системе Яндекс.
- Третья колонка — позиция сайта по запросу в поисковой системе Google.
- Четвертая колонка — частота поискового запроса (популярность) по поисковой системе Яндекс.

## Настройка популярности поисковых систем

Для корректной проверки видимости сайта — настройте относительную популярность поисковых систем Яндекс и Google в процентах (%). По-умолчанию это значения 66% и 34%.

## Загрузка данных и вывод таблицы результатов

## Данные на выходе

Вывод данных производится на этой же странице в виде HTML-таблицы следующего вида:

- Видимость сайта по каждому запросу.
- Число эффективных показов по Яндексу и Google.
- Относительная важность запроса среди группы запросов.
- Суммарное число эффективных показов по группе запросов.
- Видимость сайта по всей группе запросов.

**Все расчеты по оценке видимости сайта, также предлагается скачать в формате *.xls.**

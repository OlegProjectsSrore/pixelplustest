## Какие показатели по проекту мы отслеживаем?

- Видимость проекта в выдаче поисковых систем.
- Показатель CTRxWS по запросам.
- Количество запросов, по которым сайт находится в ТОП-3, 10, 30, 100+.
- Органический трафик.
- Интегральные показатели:
 - внутренней оптимизации
 - поведенческих факторов
 - внешней оптимизации продвигаемых URL
- Автоматический мониторинг технических и поисковых показателей:
 - контроль индексации
 - проверка изменений файла robots.txt с сохранением предыдущих версий
 - код ответа сервера продвигаемых URL
 - теги Title, H1 и их дублирование
 - корректность страницы 404-ошибки
 - регистрация домена
 - ссылочный профиль
 - изменение структуры сайта
 - наличие зеркал в поиске
 - скорость загрузки и размер продвигаемых документов
 - изменения тегов Title, H1, и мета-тегов Description на продвигаемых страницах

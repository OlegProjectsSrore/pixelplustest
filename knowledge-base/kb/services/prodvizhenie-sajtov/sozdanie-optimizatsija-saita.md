# Оптимизация структуры сайта на этапе создания

На этапе создания сайта «во главу угла» ставится удобство использования, привлекательный дизайн и
функциональность сайта. Но не всегда достаточно внимания уделяется дружелюбной (к поисковым системам Яндекс и
Google) структуре URL сайта. Впоследствии это негативно сказывается на поисковом продвижении, особенно в продвижении по высокочастотным запросам.

В частности, папка продвигаемого по запросу «гофрокартон» раздела может быть названа как: «**/gofra/**»,
«**/01/**», «**/production/**», но оптимальным и единственно правильным для продвижения было бы название «**/gofrokarton/**».
Это мелочь? Ну, если считать разницу между 1-ым и 5-ым местом в Яндексе по запросу [гофрокартон] в выдаче
мелочью — то да.

Выход из ситуации: контроль всех этапов создания сайта SEO-специалистом компании.

Можно предположить, что для выполнения поставленной задачи (создания наиболее грамотной и дружелюбной URL
структуры сайта) можно решить, используя в качестве названий папок (разделов) на сайте — **транслит**, но это
не всегда верно. Дело в том, что у поисковой системы Яндекс собственная система обработки транслитерации. Помимо
того, для использования именно нужных слов в URL (в сочетании с оптимальной их длиной) необходимо примерно
составить семантическое ядро сайта (уточнить примерный список продвигаемых запросов) и иметь **обязательный
опыт** работ по поисковой оптимизации. Таким образом, грамотно проконтролировать данную работу способен
только SEO-специалист (не менеджер, не верстальщик, не программист и не дизайнер).

Традиционно, проблему создания действенной структуры URL сайта решают либо на этапе его оптимизации, либо не
решают вовсе, но наиболее правильно задуматься о ней уже на этапе начальной разработки.

## Что также входит в стоимость услуги?

Специалист по продвижению в процессе изготовления сайта будет контролировать следующие этапы работ:

1. Создание оптимальной структуры URL страниц и разделов для дальнейшего поискового
 продвижения и увеличения видимости сайта по
 коммерческим запросам.
2. Соответствие HTML-тегов, используемых на странице, последним требованиям поисковых систем Яндекс и Google.
3. Устранение возможных дублей страниц.
4. Наличие уникальных заголовков для страниц и их соответствие теме страницы.
5. Создание текстового файла регламентирующего, работу индексирующих поисковых роботов (robots.txt).
6. Создание карты сайта для быстрой индексации новой версии сайта (sitemap.xml).
7. Настройка верного ответа сервера на запрос несуществующей страницы (страница с ошибкой 404).
8. Регистрация сайта в поисковых системах (важно для новых сайтов, разработанных на новых доменных именах).
9. Присвоение сайту правильного региона в Яндексе (это важно для продвижения по коммерческим запросам).

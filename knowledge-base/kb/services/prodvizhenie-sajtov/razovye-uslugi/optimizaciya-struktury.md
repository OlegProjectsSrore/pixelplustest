# Формирование оптимизированной структуры сайта

10 из 10 лидеров по объемам поискового трафика в e-commerce и услугах имеют оптимизированную под спрос структуру. Данный этап является обязательным не только для выхода в лидеры ниши, но и просто для широкого охвата целевой аудитории и снижения стоимости привлечения посетителей (CPC) и покупателей (CPA).

## Для чего нужны работы и на что они влияют?

1. Охват запросов из семантического ядра и потенциал роста трафика.
2. Позиции сайта по целевым запросам.
3. Удобство пользования сайтом, поведенческие факторы и конверсия.

## Полный список работ

- **Шаг 1: сбор семантического ядра, которое полностью охватывает вашу тематику.** При наличии семантического ядра — предоставляется скидка на работы.
- **Шаг 2: разделение запросов на типы.** Важно разделить общие, информационные и коммерческие запросы для дальнейшей работы. В ряде случаев — можно действовать поэтапно, прорабатывая структуру для каждого раздела по очереди.
- **Шаг 3: выбор ключевых конкурентов.** Для сокращения временных ресурсов и бюджета работ — выбираются наиболее «продвинутые» конкуренты с хорошей видимостью в поиске. Подходит, если в тематике есть ярко выраженные лидеры по объемам поискового трафика.
- **Шаг 4: получение данных запросов.** По каждой фразе собирается набор параметров, которые помогают в дальнейшей работе. В частности: коммерческий документ ищут пользователи или нет, какой количество главных страниц в выдаче, какая частота у запросов и так далее.
- **Шаг 5: маркировка групп запросов.**
- **Шаг 6: визуализация и проверка.** Создается визуальная структура, которая помогает наглядно представить результат и упрощает работу для разработчиков, продуктовых менеджеров и владельца бизнеса.
- **Шаг 7: задание URL на сайте.** Указываются конечные адреса для каждого документа на сайте. Все запросы привязываются к одному URL, который и требуется создать для успешного продвижения.

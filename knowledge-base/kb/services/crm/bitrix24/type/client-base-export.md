# Экспорт базы данных в CRM Битрикс24

Иногда информацию из Битрикс24 (список контактов, каталог товаров и т.д.) необходимо использовать вне CRM, например, для работы с другими сервисами. Базу данных можно экспортировать в несколько кликов. Интернет-агентство «Пиксель Плюс» поможет вам правильно настроить выгрузку данных.

## Как это работает

Система управления Битрикс24 позволяет экспортировать любые элементы:

- контакты;
- товары;
- лиды;
- счета;
- коммерческие предложения;
- сделки.

Информация оформляется в виде таблицы в формате .XLS или файла .CSV. Контакты можно выгрузить в Microsoft Outlook. Это удобно, если нужно разослать письма всему списку контактов.

Чтобы выгрузились только нужные данные, необходимо сначала настроить поля. Для этого надо зайти в нужный раздел (например, «Товары»), кликнуть на шестеренку и настроить список — поставить галочки в тех пунктах списка, которые нужно экспортировать. Например, артикул, размер, производитель, цена. Экспорт учитывает фильтры, которые были применены к списку. Например, можно скачать только те сделки, где ответственным назначен конкретный менеджер. Для корректной работы с контактами нужно отметить опцию «Участвует в экспорте контактов». Настройка экспорта в Битрикс24 может стать сложной задачей.

Выгруженный файл можно редактировать, импортировать в сторонние системы и сервисы.

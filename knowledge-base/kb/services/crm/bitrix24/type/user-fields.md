# Настройка пользовательских полей в CRM Битрикс24

Каждый элемент Bitrix24 содержит набор полей. Они нужны для быстрого поиска и фильтрации. ## Как это работает

Одно из преимуществ системы управления Битрикс24 – удобная фильтрация и сортировка данных. Пользователь находит нужные данные за пару кликов. При создании элементов нужно заполнить обязательные поля в форме, и данные будет включены в поиск. Но каждый бизнес работает со своим набором данных. Часто возникает необходимость добавить свои поля.

Настройка полей в CRM Битрикс24 проводится в несколько шагов:

- В карточке элемента нужно кликнуть на кнопку «создать поле».
- Выбрать тип, например, «файл» «список», «дата/время». Чаще всего выбирается строка, то есть обычный текст.
- Пользовательские поля в задачах можно сделать обязательными для заполнения или множественными (то есть с несколькими значениями).
- Дать название и сохранить.

То же самое можно сделать в разделе «CRM - Настройки - Настройки форм и отчётов - Пользовательские поля». Здесь выведен набор дополнительных опций: можно задать названия для всех языков, выбрать, показывать ли поле при фильтрации и поиске, привязать его к пользователю или разделу.

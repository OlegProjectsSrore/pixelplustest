# Создание мобильного приложения для Битрикс

Новые возможности для владельцев сайтов

В короткие сроки мы разработаем REST API и сможем быстро выпустить мобильное приложение для вашего сайта или интернет-магазина. Начните мобильную интернет-торговлю уже сегодня! Звоните нам.

**Создайте мобильное приложение на базе своего сайта.**

## Мобильные приложения помогают:

- Повысить качество обслуживания клиентов
- Удерживать клиентов
- Наладить регулярные продажи
- Задействовать новые способы маркетинга

- Предоставить своим клиентам быстрый доступ к каталогу интернет-магазина и к заказам

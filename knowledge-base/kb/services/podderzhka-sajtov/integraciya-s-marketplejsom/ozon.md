# Интеграция сайта с торговой площадкой Озон

Одним из основных этапов развития интернет-магазина является сотрудничество с маркетплэйсами — крупнейшими торговыми
площадками в интернете. Озон является одной из таких площадок, которая является посредником между продавцом и
покупателем. Благодаря большому ассортименту продукции, Озон очень популярен у пользователей. По этой причине услуга
по подключению сайта к площадке Озон — одна из самых востребованных на текущий момент, среди клиентов нашего
агентства.

Подключение к Озону возможно в двух вариантах:

1. FBO — работа со склада Ozon

Товары отгружаются на склад Ozon. Для обработки заказов не требуется никаких действий. Необходимо только
управлять ценами.

2. FBS — работа с собственного склада

Выгружаем остатки товаров на Ozon, при поступлении заказа производим отгрузку товара на склад Ozon.

Интеграция с Озоном отличается от интеграции с другими маркетплэйсами, весь контент на товар должен быть в
соответствии с требованием маркетплейса. Процедура интеграции заключается не в генерации файла-фида. Интеграция
производится посредством общения с API маркетплейса.

Базовая интеграция Bitrix с Озон — 40 часов (до 3х разделов Ozon, количество товара не ограничено).

В базовую интеграцию входит всё, что нужно для работы по FBS и FBO: выгрузка товаров (при необходимости
повторная), настройка обмена остатками, ценами, загрузка заказов на сайт.

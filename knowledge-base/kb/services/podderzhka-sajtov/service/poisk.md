# Настройка и доработка поиска по сайту

Поиск - функционал для быстрого подбора интересующего контента, который в обязательном порядке должен
присутствовать на сайте с большим количеством товаров или услуг, а также для блогов, информационных
порталов.

Корректно работающий поиск на сайте напрямую влияет на увеличение продаж на сайте. Пользователь может
легко найти
интересующую его информацию по товару, покупка становиться быстрее и проще.

Наличие поиска делает сайт более привлекательным для пользователей по сравнению с сайтами конкурентов.
Окно
поиска
по сайту должно располагаться в удобном месте на главной странице, быть видимым для лёгкого перемещения
по
нужным
страница.

Для удобства пользователей, необходимо настроить поиск таким образом, чтобы автоматически были исправлены
опечатки
и ошибки. Плюсом будет настройка «подсказок» для пользователя при вводе запроса.

Поиск по сайту, также, улучшит и ускорит индексацию в поисковике Яндекс.

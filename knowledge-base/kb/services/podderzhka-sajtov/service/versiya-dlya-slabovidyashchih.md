# Добавление версии для людей с нарушением зрения

Владельцы бизнеса используют различные инструменты и возможности для популяризации своего бренда и
привлечения
клиентов. Добавление версии для людей с нарушением зрения как раз будет являться одним из таких
инструментов.

В результате работ, вы получите отдельную версию вашего сайта, которая позволит посетителю настроить
отображение под себя. Для слабовидящих людей должна быть возможность уменьшать и увеличивать размер
шрифта. Для
дальтоников должна быть возможность изменения цветовой схемы для удобства чтения. Для дислексиков —
нужно
добавить возможность изменения межстрочного и межбуквенного интервала. Для незрячих должна быть
возможность
озвучивания информации на сайте.

При добавлении версии сайта для людей с нарушением зрения, разработчик должен руководствоваться
 ГОСТ
Р 52
872 — 2012 «Требования доступности интернет-ресурсов для инвалидов по зрению». В этом документе
выделяется три
уровня доступности.

- А — минимальная доступность.
- АА — полная доступность.
- ААА — специализированный сайт для инвалидов по зрению.

Типы сайтов которые обязаны иметь версию для людей с нарушением зрения:

- Органы государственной и муниципальной власти.
- Организации здравоохранения.
- Учебные заведения.
- Учреждения культуры и искусства.
- Социальные учреждения.

на сайте, заполните форму ниже, наш менеджер с вами свяжется.

# Создание макетов страниц

Макет страницы - это симбиоз кропотливой работы клиента, дизайнера, менеджера, маркетолога, копирайтера и
программиста.

Детальная разработка макета страницы сайта позволяет избежать издержек в бюджете и ошибок при верстке.
Качество
дизайн-макета влияет на удобство использования сайта посетителем.

На этапе разработки макета формируется структура и расположение всех элементов на странице. Учитываются
пожелания
заказчика, брендбук компании и прописанные требования в ТЗ.

## Зачем нужен макет страницы?

1. Помогает определить визуальные недостатки на первоначальном этапе проекта.
2. Воплощает наглядно дизайнерскую задумку для клиента.
3. Упрощает работу верстальщика и программиста.
4. Дает представление того, как будет выглядеть сайт.

## Этапы разработки макета страницы:

1. Определяем цель и задачи разработки, проводим маркетинговый аудит.
2. Продумываем структуру страницы.
3. Рисуем прототип (схема без дизайна, где видно расположение блоков на странице).
4. Рисуем дизайн и собираем в один файл цвета, шрифты, фото и видео.
5. При необходимости создаем макет для мобильной версии сайта.

## Основными ошибками при создании макета считают:

1. Большое количество элементов на странице среди которых, посетитель теряется и не может найти нужный
 элемент.
2. Неудачное сочетание цветов, которое раздражает посетителя.
3. Нечитаемый шрифт в тексте.

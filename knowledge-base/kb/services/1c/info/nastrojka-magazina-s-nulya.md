# Процесс настройки 1С:Магазин

Автоматизация работы любого торгового предприятия подразумевает установку оптимальной конфигурации 1С. Наибольшее распространение в этой сфере приобрела программа «Розница 8», которую опытные специалисты «Пиксель Плюс» могут установить и настроить в соответствии с особенностями конкретного магазина. Рассмотрим основные вопросы, возникающие в процессе проведения настройки.

## Этапы настройки базовой версии

### Создаем организацию

Настройку программы начинают с создания организации в разделе «Нормативно-справочная информация». В появившемся окне вносятся реквизиты (название, ИНН) компании, для которой производится настройка 1С: Магазин.

### Виды цен

Одноименная функция находится в разделе меню «Маркетинг». Создаются два вида цен:

- закупочная — заполняются пункты «Наименование», «Компоновочная схема данных», «Способ задания цены»;
- розничная — можно задать автоматическую формулу для расчета цены, по которой будет идти продажа, с наценкой на стоимость поступления товара.

### Создаем магазин

В программе 1С: Магазин именно «Магазин» — центр учета, который и будет осуществлять продажу. Для этого необходимо его создать, перейдя в «Нормативно-справочную документацию». Здесь заполняются все нужные пункты: «Название», «Наименование склада», «Организация продаж», «Правило ценообразования». Можно выбирать работу с одним или несколькими складами.

### Добавление фискального регистратора и кассы ККМ

Программный модуль «Рабочее место кассира» (РМК) не функционирует при отсутствии фискального регистратора, поэтому следует его добавить. Фискальный регистратор может использоваться в режиме онлайн-кассы или без фискальной памяти, как эмуляция.

Создать «Кассу ККМ» можно в пункте «Магазины» раздела «Нормативно-справочная информация». Здесь следует заполнить каждый пункт: «Тип кассы», «Организация» и т. д.

### Подключаем торговое оборудование

Работа оборудования настраивается в разделе «Администрирование» — «Подключаемое оборудование». Для рабочего места каждого пользователя можно подключить свой набор применяемого оборудования: сканер штрихкода, весы, принтер и другое.

### Настраиваем права пользователей

Настраивать 1С можно для продовольственной и непродовольственной розницы. В любом случае важно правильно настроить права пользователей для контроля корректной работы сотрудников через управление данными. Настройка выполняется через «Администрирование» — «Пользователи и права» — «Дополнительные права пользователей».

Если вы настраиваете программу впервые, воспользуйтесь профессиональной помощью специалистов «Пиксель Плюс». Мы решаем любые задачи по настройке программы 1С: Розница 8.3 для магазинов. Имеем большой опыт работы с различными торговыми предприятиями Москвы и других городов.

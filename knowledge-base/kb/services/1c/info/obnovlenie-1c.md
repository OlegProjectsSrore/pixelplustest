# Процесс обновления 1С

Обновление 1С осуществляется с учетом особенностей подключения базы данных. При этом версии (8.2 или 8.3) значения не имеют. Важный нюанс: если вы используете обе версии одновременно (с разными конфигурациями), вам нужно обновлять обе. Достаточно установить одну – самую последнюю версию платформы 1С: Предприятие.

## База данных в файловом варианте: особенности обновления

Такие базы данных есть у базовых версий и программ, рассчитанных на небольшое количество пользователей (до 5). Крупные предприятия работают с другими версиями 1С: Предприятие и используют СУБД MS SQL или иные решения. Обновления версии требуют:

- установки новой конфигурации (загрузив с сайта 1С, из программы или диска);
- установки новой платформы (при необходимости);
- обновления конфигурации.

Установка конфигурации выполняется автоматически, если она была загружена из программы. В других случаях установку следует запустить вручную. Для этого используют вкладку «Конфигуратор», а в меню выбирают «Обновить конфигурацию». Программа определит версию, которая подходит вам, и предложит ее установить. Результат – типовая конфигурация.

## Установка с СУБДД PostgreSQL и MS SQL

SQL используют для программ для бухгалтерии в крупных компаниях и на платформах с нестандартной конфигурацией. Этот вариант подойдет для любого предприятия. С обновлением файлов помогут те же источники: сайт 1С или диск. Сервер 1С также необходимо обновить после того, как основные работы будут проведены.

Перед тем, как обновлять программу, нужно сделать резервную копию: в случае необходимости вы сможете вернуться к предыдущей версии и снова попытаться загрузить новые файлы.

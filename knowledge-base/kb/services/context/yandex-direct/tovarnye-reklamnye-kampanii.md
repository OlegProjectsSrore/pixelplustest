# Реклама товаров в поиске и РСЯ

Лучший инструмент для того, чтобы сделать запуск рекламы интернет-магазинов быстрее, проще и эффективнее с помощью объединения преимуществ рекламы на Поиске и в Рекламных сетях.

Для создания товарной рекламной кампании необходимо подготовить фид — файл, содержащий данные товарной матрицы.
Система на основе этих данных формируют объявление в соответствии с запросами пользователя по всем
представленным в фиде товарным позициям.

# Смарт-баннер в Яндекс Директ для вашей рекламной кампании

Смарт-баннер — медийный формат рекламных объявлений с динамическим контентом в Яндекс Директ, показывающийся только в рекламных сетях Яндекс (РСЯ) и внешних сетях. Оплата происходит за клик по баннеру (CPC-модель).

Для создания смарт-баннера необходимо подготовить фид — файл, содержащий данные товарной матрицы. Система на основе фида формируют объявление в соответствии с запросами пользователя.

## Стоимость размещения

- Стоимость за 1 клик для смарт-баннера от 3 рублей без учёта НДС.
- Минимальный размер заказа в Яндексе от 1 000 рублей без учёта НДС.

Цены за клик и общий бюджет проекта рассчитывается отдельно для каждой тематики с учетом географического и временного таргетингов.

Минимальный рекомендованный бюджет для кампании от 40 000 рублей.

## Отличительная особенность смарт-баннера

Показ баннера пользователю осуществляются с учетом его индивидуальных предпочтений по условию ретаргетинга (кто уже был на сайте и совершил целевое действие) или по поведенческому фактору (интересу пользователя к подобного рода товару).

Фид может содержать как весь ассортимент товаров/услуг рекламодателя, так и только категорию, которую необходимо продвинуть.

Смарт-баннеры подходят для интернет-магазинов с широким ассортиментом, компаниям по продаже автомобилей, туристических услуг, недвижимости и ряду других тематик.

## Для каких целей подходит смарт-баннер?

- Необходимо увеличить трафик из РСЯ.
- Необходимо рассказать о товаре/услуге.
- Необходимо напомнить аудитории об интересующем ее предложении.
- Увеличение числа продаж.
- Увеличение узнаваемости компании.

# Программа лояльности для клиентов по контекстной рекламе

Для клиентов, сайты которых агентство «Пиксель Плюс» продвигает через контекстную рекламу, мы сформировали
программу лояльности. Она включает в себя скидки и различные бонусы. Мы определили, какие смежные услуги
интересуют наших клиентов и просто решили дать на них скидку либо вообще оказать их бесплатно.

| Описание | Скидка или бонус |
| --- | --- |
| С 1-го месяца работы | |
| --- | --- |
| Скидка на дополнительную услугу агентства: SEO, поддержка или создание сайтов, SMM, таргетированную рекламу, продвижение на маркетплейсах, ведение блога в Яндекс.Дзен, ведение и продвижение канала на Youtube | -10% |
| Скидка за ведение контекстной рекламы для второго и третьего сайта | -10% на второй проект и -15% на третий |
| Скидка за проект, пришедший по вашей рекомендации | -10% на комиссию за ведение |
| С 5-го месяца работы | |
| Создание магазина на одной из платформ на выбор: Ozon, Wildberries или Яндекс Маркет. Создание 5 карточек товаров* | Бесплатно |
| Юзабилити аудит AskUsers (минимальный пакет)* | Бесплатно |
| Написание трех статей / постов для любой социальной сети или Яндекс.Дзен* | Бесплатно |
| Создание и оформление страницы в любой социальной сети* | Бесплатно |
| Создание и оформление канала в Яндекс.Дзен или YouTube* | Бесплатно |
| С 8-го месяца работы | |
| Настройка рекламных кампаний внутри одной из платформ на выбор: Ozon, Wildberries или Яндекс Маркет* | 1 месяц бесплатно |
| Подключение коллтрекинга (минимальный пакет) * | 1 месяц бесплатно |
| Настройка и ведение таргетированной рекламы в ВКонтакте или MyTarget * | 1 месяц бесплатно |

*услуги предоставляются на выбор

Чтобы воспользоваться скидками или бонусами, достаточно спросить вашего аккаунт-менеджера о программе
лояльности. Ну а в случае, если вы еще не являетесь нашим клиентом — заполнить заявку, размещенную ниже.

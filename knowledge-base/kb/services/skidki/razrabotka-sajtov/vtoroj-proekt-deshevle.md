# Ваш второй сайт — на 10% дешевле!

Уже разрабатывали с нами сайт? Отблагодарим за доверие — следующий проект сделаем со скидкой 10%.

Акция «Второй проект дешевле» предоставляет скидку 10% на любой следующий проект по разработке сайта после завершения первого. Скидка применяется автоматически при подтверждении предыдущего заказа, действует на полную стоимость нового проекта и доступна бессрочно — но только один раз, на второй проект. Акция не суммируется с другими спецпредложениями.

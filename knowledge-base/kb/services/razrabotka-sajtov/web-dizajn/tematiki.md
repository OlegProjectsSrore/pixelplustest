# Дизайн сайта вашей тематики

Услуга по разработке уникального веб-дизайна сайта с учетом вашей тематики станет оптимальным решением для представительства бизнеса в интернете.

## Что входит?

Главная страница

Изготовление дизайна сайта главной страницы, которая и станет основой для
остальных типовых страниц сайта, задаёт стиль оформления элементов навигации, типовых информационных блоков.

Типовая внутренняя страница

Дизайн типовой внутренней страницы, стандарты оформления заголовков,
подзаголовков, вёрстки текста, стиль оформление таблиц, списков.

Типовая страница раздела каталога

Дизайн страницы каталога, формат подачи информации, отрисовка
тематических тизеров и иконок.

Типовая страница детального просмотра элемента

После выпуска проекта наша команда проведет аналитику и предложит
рекламный канал подходящий именно вашему бизнесу! Это может быть SEO оптимизация, настройка контекста или
таргетированной рекламы.

Страница с контактной информацией

Дизайн страницы с контактной информацией, отрисовка схемы проезда.

## Какие виды сайтов поддерживает Webflow

Webflow — популярный конструктор для лендингов и сайтов небольшого и среднего размера. Основная
особенность Webflow — работа с HTML, CSS и JavaScript с помощью визуального редактора, без использования самого
кода. Webflow генерирует чистый код, готовый к публикации или передаче разработчикам, для дальнейшей верстки на
других CMS.

## Преимущества Webflow

Webflow выполняет поставленные задачи именно за счёт объединения HTML и JavaScript в визуальном
редакторе. В интерфейсе можно быстро управлять содержимым и структурой сайта. У платформы есть и другие
преимущества:

Дизайн-система

Webflow может сохранять и повторно использовать
CSS-классы, HTML-компоненты и библиотеку цветов. Это позволяет использовать платформу как пространство для
улучшения дизайн-системы проекта.

Визуальный редактор

Раздел дизайнера дает возможность наблюдать
результат верстки в режиме реального времени. По сравнению с другими конструкторами сайтов, Webflow дает
широкий набор настроек стилей CSS.

SEO-дружелюбность

Технические параметры Webflow имеют широким набором функций, которые
помогают повысить позиции сайта в поисковых системах.

Экспорт чистого кода

Webflow дает возможность экспорта кода проекта
HTML, CSS, JS и медиа-исходниками. Это позволяет использовать сверстанные в Webflow страницы на других
платформах, в частности, на WordPress или 1С-Битрикс.

Несмотря на простоту платформы, заказать создание сайта на Webflow лучше у профессиональных разработчиков.

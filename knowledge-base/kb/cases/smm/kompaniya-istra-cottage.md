# Кейс создания и оформления группы ВКонтакте для сайта базы отдыха

## Анализ

С марта 2017 года по октябрь 2018 в группе было размещено 7 публикаций, охват одной записи составлял порядка
40 пользователей. Из основных инструментов использовались только личные сообщения.

В ходе аудита были выявлены следующие проблемы:

- некорректный URL, имя и статус сообщества;
- неактуальные данные в описании;
- отсутствует виджет, приложение и активные кнопки в шапке сообщества;
- отсутствует обложка и оформление аватара с контентом;
- не разработан общий стиль и цветовая палитра для группы;
- отсутствует контент-план и не налажен регулярный постинг.

## Решение

Изменение информации

В ходе оптимизации и настройки были изменены:

- общий блок информации;
- добавлен триггер в статус «снижение цен на осенне-зимний период»;
- была осуществлена гео-привязка, установлен номер телефона с активной кнопкой «позвонить», режим работы и приветственное сообщение в ЛС;
- добавлены ключевые слова в URL и имя группы, для улучшения ранжирования во внутреннем поиске ВКонтакте.

Разработка общего стиля и оформления группы

На основе имеющегося брендбука, разработанного ранее для сайта клиента отделом брендинга и дизайна в компании «Пиксель Плюс», были созданы:

- обложка с указанием триггера «Снижение цен на осенне-зимний период»;
- аватар с логотипом базы отдыха;
- шаблоны оформления публикаций для ленты сообщества.

Приложение и приветственный виджет

Для вовлечения подписчиков и призыва к действию для коммуникации с брендом, в сообществе был установлен приветственный виджет с призывом подписаться на актуальные новости бренда.

Также, было подключено приложение «Рассылка» для сбора базы релевантных фолловеров с целью создания воронки продаж.

По состоянию на январь 2019 года, подписчиками рассылок стали 13 человек

Итог

В результате проведенных работ был разработан дизайн для оформления сообщества, общий стиль и гайдлайн для оформления публикаций.

Были актуализированы и изменены основные блоки информации, в результате, сообщество стало появляться в ТОП-10 по внутренним ключевым запросам ВК.

Был разработан контент-план и рубрикатор на месяц, с приложениями в виде редакционного плана и референсов для клиента.

Подключены инструменты для внутреннего взаимодействия с подписчиками.

# Кейс по настройке, запуску и ведению таргетированной рекламы через Facebook Ads для компании, специализирующейся на утеплении квартир, частных и промышленных строений в Москве, Подмосковье и других городах России

## Решение

- Проведен анализ ЦА, выявлены наиболее конверсионные сегменты.
- Выявлены основные боли ЦА, которые сможет решить утепление помещений.
- Под каждую из болей сверстан отдельный креатив и написан рекламный текст, содержащий в себе: проблему, с которой сталкивается пользователь, решение проблемы, преимущества рекламодателя и CTA.
- Через пиксель Fb настроено отслеживание целей, что позволило выбрать в качестве стратегии оплату за конверсии.
- Настроены и запущены рекламные кампании в Facebook и Instagram с разбивкой на регионы, группы ЦА и боли, которые помогает решить утепление.
- Проведен анализ при помощи различных сервисов аналитики по результатам которого внесены корректировки рекламных кампаний.

## Результаты проведённых работ

Рост онлайн-заявок на 9%

CPL 220 руб

CR 5,79 %

Отказы 0 %

Итог

- В результате тестовой РК были выявлены наиболее эффективные креативы и сегменты аудитории, на которые был увеличен бюджет.
- Стоимость заявки составила 220 руб, а по наиболее эффективным креативам и сегментам — 179 руб.
- Показатель отказов составил 0 % (против 3,6 % из контекстной рекламы).
- Конверсия составила 5,79 % (против 3,1 % из контекстной рекламы).
- По результатам 1 месяца работ было решено запустить таргетированные рекламные кампании в социальных сетях Вконтакте и Одноклассники.

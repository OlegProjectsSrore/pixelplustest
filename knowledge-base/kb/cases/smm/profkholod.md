# Кейс по SMM-продвижению сайта компании, занимающейся производством сэндвич-панелей с инновационным утеплителем из пенополиуретана.

ООО «ПрофХолод»

«ПрофХолод» — крупнейший в России производитель сэндвич-панелей с инновационным утеплителем из пенополиуретана. Компания создает уникальные новые продукты для управления теплом на основе мирового опыта и используя лучшие зарубежные материалы.

Услуги SMM

Начало сотрудничества:

февраль 2021 года

Основные работы:

таргетированная реклама в Facebook

01

Увеличить целевой трафик на сайт

02

Наладить лидогенерацию из Facebook с помощью формы сбора заявок

## Решение

- Настроены кампании на поиске и РСЯ с учетом особенностей тематики и привязке по геотаргетингу. Проведён анализ конкурентов, анализ ЦА, определен портрет аудитории и конверсионные сегменты для рекламной кампании.
- Подготовлены тексты и креативы для рекламной кампании на основании фирменного стиля клиента.
- Настроены и оптимизированы Бизнес-цели в Facebook Ads для выполнения поставленных задач.
- Настроены формы сбора заявок в Facebook Ads.
- Проведена настройка и сегментирование аудитории с учётом интересов детального таргетинга и ГЕО.
- Проведен запуск рекламных кампаний.
- Производится регулярный анализ и оптимизация рекламных кампаний с целью улучшения показателей. Регулярное отслеживание показателей и оповещение клиента о новых заявках в формах генерации лидов.

## Результаты проведённых работ

СРС 10,36 руб

Стоимость лида 373,66 руб

CTR 1,05%

Итог

- Выполнены главные задачи по обеспечению трафика и заявок.
- Достигнуты низкие показатели CPL и CPC.

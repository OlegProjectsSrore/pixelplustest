# Поисковое продвижение сайта компании «Magbo»

«Magbo» — интернет-магазин, специализирующийся на продаже сантехники, керамической плитки, мебели для ванных комнат, климатической техники и других строительных и отделочных материалов.

Перейти на сайт: magbo.ru

Описание работ

1. **Технический аудит и базовая оптимизация**
 - Провели комплексный технический аудит сайта — выявили критические ошибки индексации и проблемы с доступностью страниц для поисковых роботов.
 - Устранили базовые технические ошибки — исправили некорректные теги и мета-теги, настроили автоматическую генерацию sitemap.xml, убрали дублирование меню в исходном коде, вынесли ссылки из HTML в хедер и футер.
 - Настроили региональную привязку сайта и подключили панели вебмастеров — получили доступы к Яндекс.Вебмастер, Google Search Console, внедрили микроразметку schema.org для основных типов страниц.
2. **Работа с индексацией и структурой сайта**
 - Решили проблемы с индексацией страниц — внесли корректировки в файл robots.txt, исправили ошибки в sitemap.php и настроили правильную генерацию карт сайта под требования Google.
 - Подключили Яндекс.Товары и Google Покупки — настроили и загрузили YML-фиды с актуальными данными о товарах.
 - Открыли фильтровые страницы для индексации — внедрили автоматическую генерацию title, description и h1 по шаблонам, что значительно увеличило количество проиндексированных страниц.
 - Массово создали новые страницы — запустили создание страниц через модуль умного SEO «Аспро», внедрили шаблонные тексты на поддоменах, добавили кликабельные параметры в карточки товаров.
3. **Контентная оптимизация и семантическое ядро**
 - Собрали и расширили семантическое ядро — провели сбор коммерческой семантики, сформировали файл распределения запросов по страницам, ежеквартально расширяли СЯ на основе анализа конкурентов.
 - Написали и разместили значительный объём уникального контента — подготовили тексты для приоритетных страниц, создали информационные статьи, добавили описания к карточкам товаров.
 - Провели ручную оптимизацию мета-тегов — написали title, description и h1 для приоритетных страниц, уникализировали дублирующиеся заголовки.
 - Внедрили контекстную внутреннюю перелинковку — добавили ссылки на релевантные разделы, разместили блоки с полезными материалами, вывели ссылки на страницы фильтров.
4. **Работа с конверсионными элементами**
 - Добавили отзывы к товарам — усилили доверие пользователей и улучшили показатели E-E-A-T для коммерческих страниц.
 - Скорректировали адаптивную версию листингов — убрали тег noindex с облака тегов, исправили отображение характеристик, доработали вывод баннеров для мобильных устройств.
 - Провели расширенный конверсионный аудит — проверили работоспособность форм обратной связи, реализовали поп-ап для улучшения коммуникации с клиентами.
5. **Конкурентный анализ и техническая поддержка**
 - Провели глубокий анализ конкурентов — изучили трафиковые страницы для сбора семантического ядра, проанализировали структуру успешных сайтов.
 - Применили продуктовый подход к SEO — приоритизировали задачи на основе влияния на рост трафика, тестировали гипотезы на поддоменах перед масштабированием.
 - Оперативно решали критические проблемы — исправляли технические ошибки, ускорили работу сайта через конвертацию изображений в WebP, обеспечивали стабильность работы проекта.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить поисковый трафик в 2 раза — достигли прироста на 101% за период работ без учёта брендовых запросов.
- Снизить стоимость привлечения посетителя вдвое — CPC сократилась с 15,68 до 7,8 рублей, что на 50% эффективнее первоначальных показателей.
- Заняли лидирующие позиции в ТОП-3 — вывели сайт на первые позиции Google и в топ Яндекса по ключевым коммерческим запросам.
- Увеличили долю поискового трафика до 83% — поисковые системы стали основным каналом привлечения целевой аудитории.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише оптовой торговли одеждой.

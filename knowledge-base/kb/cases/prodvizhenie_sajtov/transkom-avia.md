# Поисковое продвижение сайта компании «ТрансКом-Авиа»

«ТрансКом-Авиа» — агентство, специализирующееся на продаже грузовых авиаперевозок и организации смешанной доставки грузов по России и за рубежом, с представительствами в аэропортах Домодедово, Шереметьево и Внуково.

Перейти на сайт: transcomavia.ru

Продвижение сайтов
Грузоперевозки
Корпоративный сайт

Начало сотрудничества:

февраль 2015 года

Основные работы:

поисковое продвижение

Цель:

увеличение небрендового поискового трафика на сайт

Описание работ

1. **Проработали контент**
 - Написали уникальные SEO-тексты для целевых страниц по ключевым направлениям авиаперевозок, в том числе отдельный материал для страницы перевозки живых животных.
 - Провели рерайт главной страницы сайта с учётом актуальных коммерческих запросов.
 - Согласовали написанные тексты с клиентом и разместили их на сайте.
 - Добавили редактируемые блоки текста на главную страницу.
 - Внедрили блок «Ответы на вопросы» на целевые страницы — под частые пользовательские запросы в поиске.
 - Добавили блок «Популярные направления» для охвата семантики и улучшения внутренней навигации.
 - Дополнили таблицы характеристиками на страницах услуг.
2. **Расширили и почистили семантику**
 - Расширили семантическое ядро: выявили новые коммерческие запросы и проработали под них посадочные страницы.
 - Очистили семантическое ядро от нерелевантных и дублирующихся запросов.
 - Провели анализ конкурентов и определили точки роста для дальнейшего продвижения.
3. **Устранили технические проблемы**
 - Обнаружили и оперативно устранили критическую уязвимость платформы «Битрикс».
 - Настроили корректный регистр для GET-параметров, устранив технические дубли страниц.
 - Обновили SEO-модуль сайта до актуальной версии.
 - Удалили страницы с кодом ответа 404 из структуры сайта.
 - Деактивировали малоэффективные страницы, создававшие проблемы с индексацией.
 - Развернули тестовую копию сайта и настроили Git для безопасного внедрения изменений.
4. **Улучшили пользовательский опыт**
 - Провели оценку скорости загрузки страниц на мобильных устройствах и десктопе, после чего запустили оптимизацию.
 - Реализовали макет закреплённой сокращённой шапки сайта для мобильных устройств.
 - Оценили и внедрили выпадающий список для нижней формы «Заявка на авиаперевозку».
 - Скорректировали вёрстку баннера, блока «Отраслевые решения» и страницы «Тарифы».

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Устранить технические ошибки, мешавшие корректной индексации сайта.
- Расширить охват коммерческой семантики за счёт новых посадочных страниц и контента.
- Улучшить пользовательский опыт на мобильных устройствах и десктопе.
- Выстроить систему регулярного мониторинга, анализа и планирования улучшений.
- Обеспечить устойчивые позиции в ТОП-10 Яндекса и Google по целевым коммерческим запросам.

Такой подход создал прочный фундамент для стабильного роста поискового трафика и увеличения количества заявок через органический поиск.

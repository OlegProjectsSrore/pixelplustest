# Продвижение интернет-магазина Мир 4х4, кейс по раскрутке сайта по Москве в тематике продажи оборудования для тюнинга автомобилей

Магазин «Мир 4х4» в Москве предлагает широкий ассортимент оборудования для тюнинга внедорожной техники. С его помощью можно улучшить внедорожные характеристики авто, его надежность и выносливость. Ассортимент интернет-магазина «Мир 4х4» позволит подобрать все необходимое, чтобы подготовить машину к штурму самого сурового бездорожья.

Отзыв клиента

Цель проекта — вывод в ТОП-10 большей части запросов из семантического ядра и увеличение количества заявок с сайта.

В начале работ по проекту его видимость составляла всего 12%. Основной причиной низких позиций было: отсутствие листингов с товаром с указания цен, малое количество текстов, как в коммерческих, так и информационных категориях.

Благодаря комплексной технической оптимизации сайта и активным работам по наполнению каталогов, систематическому написанию SEO-копирайта и статей в короткий промежуток времени, удалось значительно увеличить показатель видимости. На текущий момент он составляет 48%, а сайт является лидером в своей тематике по продаже оборудования для тюнинга авто.

Помимо стандартных работ по SEO, наши специалисты столкнулись с проблемой взлома сайта и размещением на нем спамного контента. По этой причине поисковой системой Яндекс был наложен фильтр АГС, но уже через месяц в результате наших действий по выводу сайта из-под санкций, данный фильтр был снят.

Итог

В результате проведения комплекса работ по оптимизации и наполнению проекта, специалисты компании «Пиксель Плюс» достигли следующих успехов по проекту:

- в ТОП-10 Яндекса находится более 80% запросов, в ТОП-10 Google – 62%;
- видимость проекта по ключевым запросам увеличилась с 12% до 48%;
- сайт стал лидером в своей тематике, привлекая качественный целевой трафик;
- оперативные устранение последствий взлома сайта и снятия последовавших санкций со стороны поисковых систем.

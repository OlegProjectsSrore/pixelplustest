# Кейс по продвижению сайта грузоперевозок ГК Максима, увеличение целевого трафика по тематике «грузоперевозки»

АО «ГК «Максима» осуществляет свою деятельность в сфере грузовых авиационных перевозок уже в течении 15 лет. За эти годы накоплен огромный опыт по организации доставки грузов авиа и наземным транспортом по территории России и за рубежом. Компания предоставляет своим клиентам полный пакет услуг, связанных с доставкой грузов в пункт назначения.

**Цель проекта** — увеличить целевой трафик и количество обращений.

Описание работ

На старте работ клиента выбрал стандартный для многих KPI — продвижение по фиксированному списку целевых запросов.

По факту достижения высоких показателей видимости по первоначальному семантическому ядру, стало понятно, что для дальнейшего развития проекта необходимо переходить на тариф более отвечающий потребностям клиента — трафик.

Для увеличения целевых визитов по проекту проводятся:

- регулярные аудиты технической составляющей;
- поиск возможных точек роста;
- анализ целевых запросов и их расширение;
- аудит коммерческих факторов и юзабилити сайта;
- оптимизация существующих страниц и создание новых.

Выполнение комплекса работ по поисковому продвижению сайта позволило за полгода увеличить посещаемость сайта более чем в два раза.

На текущий момент компания «Пиксель Плюс» успешно продолжает работу по поисковой оптимизации сайта, а также регулярно прорабатывает новые точки роста для развития бизнеса клиента.

Итог

С начала работ по проекту, специалисты компании «Пиксель Плюс» учитывали специфику бизнеса клиента и гибко подстраивали KPI проекта под его нужды. За счет продуктивных работ удалось показать следующие результаты:

- поисковый трафик увеличился на 384%, без учета брендовых запросов;
- продвинуть в ТОП-10 Яндекса большую часть целевых запросов;
- CPC сократилась на 77.48% раза до уровня 24.5 рубля/посетитель;
- стоимость одного обращения сократилась на 4112.5 рублей/посетитель.

# Трафиковое продвижение интернет-магазина Askona, кейс по раскрутке сайта в Яндекс и Google по тематике «товары для сна»

Торговый дом Askona — лидер индустрии товаров для сна России, крупнейшая фабрика по производству анатомических матрасов в Восточной Европе.

Askona входит в состав шведского концерна Hilding Anders Group — лидирующего производителя кроватей и матрасов в Европе и Азии. Концерн Hilding Anders присутствует на 27 Европейских и 13 азиатских рынках.

«Аскона» — это гарантия полноценного отдыха: каждый третий россиянин спит на матрасе Askona. Одна из причин этого — строгий контроль качества продукции в собственной лаборатории сна - единственной в России испытательной лаборатории для мягкой мебели, сертифицированной ISO тестирующей по европейским стандартам.

Цель проекта — рост небрендового трафика из поисковых систем.

На старте работ по проекту сотрудниками компании «Пиксель Плюс» была разработана индивидуальная стратегия развития сайта с четкими KPI — увеличение роста небрендового трафика из поисковых систем.

На протяжении нескольких месяцев проводился внушительный фронт работ, как по SEO-задачам (от стандартных работ по оптимизации до переработки структуры сайта), так и по задачам поддержки сайта.
В результате проведенных работ получили значительный рост поискового трафика не только по среднечастотным и низкочастотным запросам, но и по таким высокочастотным запросам как: [купить матрас], [матрас], [матрас цена], которые находятся в ТОП-10 позиций в ПС Google и Яндексе.

На текущий момент по проекту идёт рост трафика из поисковых систем, при этом ещё виден приличный потенциал. Специалисты «Пиксель Плюс» продолжают работать над дальнейшим позитивным изменением KPI.

## Анализ прироста поискового трафика

Трафик из поисковых систем за период декабрь 2017-2020 годов вырос на 261% без учета брендовых запросов.

Анализ конверсии сайта

Конверсия сайта по органическому трафику с декабря 2017 года увеличилась на 74% без учета брендовых запросов. Следовательно, качество переходов из поисковых систем показало рост.

Стоимость одного обращения (через доступные формы обратной связи) сократилось на 59,1%. При этом в расчете не учтены иные обращения, которые могут быть оформлены через контактные номера на сайте, а также другие возможные формы обратной связи или непосредственные посещения клиентами салонов продаж.

Итог

Благодаря профессионализму сотрудников компании «Пиксель Плюс» за время сотрудничества по проекту удалось достичь главную цель — увеличить целевой трафик из поисковых систем, при этом сохранив его качество. Рост числа переходов более чем в 3.5 раза без брендовых запросов.

Специалисты компании «Пиксель Плюс» успешно продвинули наиболее актуальные и популярные запросы ТОП-10 Яндекса, такие как [кровать] – 1 место, [матрас] – 2 место. При этом их число в первой десятке постоянно растет, а сам объем прорабатываемого семантического ядра постоянно уже приближается
 к 15 000 запросам.

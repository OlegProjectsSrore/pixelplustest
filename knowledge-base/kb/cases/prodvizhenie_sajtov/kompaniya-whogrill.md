# Продвижение интернет-магазина грилей Whogrill, рост целевого трафика для тематического магазина в Москве и Санкт-Петербурге

Компания WHOGRILL — авторизированный дилер грилей, представляющий широкий ассортимент продукции всемирно известных производителей, таких как Weber, Napoleon, CharBroil, Big Green Egg и других марок.

Отзыв клиента

Сотрудничество компании «Пиксель Плюс» с проектом Whogrill началось с 2014 года и успешно продолжается в сфере интернет-продвижения и привлечения новых покупателей.

В качестве схемы сотрудничества было выбрано продвижение по трафику, и на протяжении всего периода работ обеспечивается его стабильный прирост. При этом, сайт входит в число лидеров по видимости в своей тематике, в том числе по наиболее конкурентным фразам.

Весной 2017 года был открыт магазин Whogrill в Санкт-Петербурге. Сайт успешно добавлен в Яндекс.Каталог для привязки дополнительного региона и уже занял лидирующие позиции по сотням поисковых запросов.

Прирост трафика с начала работ по поисковой оптимизации

Трафик из поисковых систем за период с марта 2014 года по август 2017 года вырос на 2756%. Абсолютное значение приближается к 7 тысячам переходов в месяц, без учета брендовых запросов.

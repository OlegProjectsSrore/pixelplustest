# Поисковое продвижение сайта компании «Ra Be Ru»

«Raberu» — сервис для поиска работы и подбора персонала в Москве. Предоставляет актуальные вакансии, удобный отклик для соискателей и инструменты для работодателей, позволяющие быстрее находить подходящих кандидатов.

Перейти на сайт: raberu.ru

Описание работ

1. **Базовая структура и семантическое ядро**
 - В начале продвижения проект требовал комплексной проработки структуры сайта и создания системы листингов вакансий. Отсутствовала оптимизация под региональный поиск, не была выстроена структура внутренней перелинковки.
 - Заведили и настроили проект в системе «Пиксель Тулс», провели поиск близких конкурентов и выгрузили семантическое ядро по конкурентам. Определили способы создания массового количества страниц под поисковый спрос, запустили задачи по созданию листингов вакансий из пересечения параметров фильтрации и запросов из поиска на сайте.
2. **Создание и оптимизация листингов вакансий**
 - Основной объём коммерческого трафика в тематике трудоустройства приходится на запросы по конкретным профессиям и городам.
 - Реализовали масштабную работу по созданию листингов вакансий под поисковый спрос — итеративно добавили страницы под различные профессии и специальности. Для каждого листинга настроили базовую оптимизацию шаблонов тегов и мета-тегов, провели корректную оптимизацию региональных подпапок с внутренней перелинковкой.
 - Добавили текстовое описание на главные страницы по городам, создали функционал добавления вакансии в «Избранное» для улучшения пользовательского опыта. Настроили региональную привязку сайта для повышения видимости в региональном поиске.
3. **Оптимизация структуры и навигации**
 - В сегменте трудоустройства критически важна удобная навигация и качественная внутренняя перелинковка для удержания пользователей и распределения веса страниц.
 - Внедрили внутреннюю перелинковку за счет блока «Похожие вакансии» и плитки тегов на листингах. Вывели блок «Похожие вакансии» на страницы компаний, увеличили количество вакансий на листингах для повышения полноты информации.
 - Отрисовали макеты превью вакансий и карточки вакансии с улучшенным визуальным оформлением. Вывели дату публикации вакансии в превью для повышения актуальности информации. Отрисовали макет плитки тегов для структурированной навигации.
4. **Наполнение информационных разделов**
 - Провели наполнение страницы «О компании» для формирования доверия у пользователей. Отрисовали макет страницы «Работодателям» с детальной информацией об услугах.
 - Добавили информацию на главный экран о тематике сайта, что позволило повысить понимание целевой аудитории о специализации ресурса. Написали текстовый контент для усиления информационной составляющей.
5. **Техническая и структурная оптимизация**
 - Провели комплексную техническую доработку сайта. Проверили доступы к FTP/CMS, наличие в CMS базового функционала и устранили стандартную уязвимость CMS Bitrix.
 - Закрыли от индексации страницы с GET-параметрами, что улучшило индексный бюджет. Настроили HTTP-заголовок Last-Modified для корректной работы с поисковыми роботами. Проанализировали наличие и корректность микроразметки Schema.org для основных типов страниц.
 - Провели регулярное сканирование сайта через Screaming Frog SEO Spider, искали ошибки индексации в обеих поисковых системах. Корректировали файл приоритета и файл SCORE для управления весом страниц. Проверяли и корректировали файл распределения.
6. **Настройка аналитики и отслеживания конверсий**
 - Настроили цели через Яндекс Метрику для отслеживания эффективности продвижения. Проводили регулярную проверку реализации правок после релиза.
 - Анализировали динамику небрендового органического трафика, отслеживали ключевые метрики эффективности. Проверяли выполнение задач на стороне клиента и контролировали реализацию правок из технического аудита.
7. **Улучшение пользовательского опыта**
 - Подготовили рекомендации по оптимизации архивных вакансий, формировали рекомендации для страниц вакансий, которые отправляются в архив. Подготовили рекомендации по настройке страниц пагинации для корректной индексации.
 - Подготовили рекомендации по оптимизации скорости загрузки страниц, донастройке строки поиска и выводу дополнительных параметров фильтрации. Подготовили рекомендации по доработке листингов для повышения конверсии.
 - Разработали техническое задание по настройке перелинковки в карточках вакансий, подготовили ТЗ на наполнение хабовой страницы компаний и корректировку адреса в карточках вакансий.
8. **Подключение в поиске Яндекса**
 - Подключили услуги и предложения в поиске Яндекса через настройку и загрузку YML-фидов в Яндекс Вебмастер. Подготовили рекомендации по заполнению профиля в Яндекс Бизнес для усиления локального присутствия.
 - Подготовили техническое задание на размещение ссылки на скачивание приложения с отрисовкой макета для увеличения мобильной аудитории.
9. **Стратегия внешнего продвижения**
 - Разработали и реализовали комплексную ссылочную стратегию. Провели закупку качественных внешних ссылок с тематических ресурсов в течение трёх месяцев.
 - Подготовили статьи для размещения обратных ссылок на внешних ресурсах, что позволило усилить ссылочный профиль и повысить авторитетность домена.
10. **Анализ конкурентов и точки роста**
 - Проводили регулярный анализ конкурентов, искали точки роста для продвижения. Анализировали страницы с резюме у конкурентов, изучали трафикогенерирующие страницы основных игроков рынка.
 - Составили семантическое ядро для Москвы, актуализировали план работ и файл приоритизации для фокусировки на наиболее перспективных направлениях.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить трафик в 47,4 раза или на 4640% — за 7 месяцев работ обеспечили стабильный рост посещаемости без учёта брендовых запросов.
- Снизить CPC на 98% — стоимость привлечения одного пользователя упала с 589,74 до 12,44 рублей.
- Достичь доли небрендового трафика 56,14% — сайт привлекает целевую аудиторию по широкому спектру коммерческих запросов.
- Вывести в ТОП-10 целевые запросы — по ряду ключевых фраз в тематике трудоустройства, вакансий и услуг для работодателей сайт занимает лидирующие позиции.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише трудоустройства.

# Поисковое продвижение сайта компании «AKB MOSCOW»

«AKB Moscow» — компания, занимающаяся продажей аккумуляторов для автомобилей, спецтехники и различного оборудования. Предлагает широкий выбор продукции разных брендов, а также помощь в подборе подходящего решения.

Описание работ

1. **Технический аудит и настройка**
 - Выполнили комплексный технический аудит сайта — просканировали структуру и выявили критические технические ошибки, влияющие на индексацию и ранжирование.
 - Устранили базовые технические проблемы с помощью системы «Пиксель Тулс» — исправили ошибки серверных ответов, настроили корректные редиректы и оптимизировали внутреннюю перелинковку.
 - Настроили региональную привязку сайта и цели для отслеживания конверсий, получили доступы к панелям вебмастера Яндекс.
2. **On-page оптимизация и техническая доработка**
 - Провели глубокий анализ позиций сайта — корректировали оптимизацию страниц на основе данных о позициях в поисковых системах.
 - Доработали блок фильтрации товаров — улучшили пользовательский опыт и поисковую индексацию каталога.
 - Скрыли из кода все ненужные ссылки на URL с GET-параметрами — очистили структуру сайта от технического мусора.
3. **Структурная оптимизация**
 - Доработали сортировку товара в листингах — обеспечили логичную навигацию по каталогу аккумуляторов.
 - Устранили проблемы долгого ответа сервера — ускорили загрузку страниц для улучшения поведенческих факторов.
 - Объединили дублирующиеся страницы — устранили каннибализацию ключевых запросов.
4. **Контентная оптимизация**
 - Создали страницы в подборе по авто для китайского автопрома — расширили семантическое покрытие нишевых запросов.
 - Оценили спрос на АКБ по округам, районам и метро — создали геозависимые страницы для улучшения локального SEO.
 - Создали страницы по станциям метро — охватили локальные поисковые запросы жителей Москвы.
 - Доработали детальные страницы статей — добавили pop-up с УТП, баннер с промокодом, слайдер с товаром в первом экране.
5. **Техническая оптимизация разметки**
 - Исправили структурированные данные — устранили все замечания по микроразметке для улучшения сниппетов.
 - Доработали первый экран мобильной версии и ПК — улучшили пользовательский опыт и поведенческие факторы.
 - Добавили блок со ссылками на популярные марки и модели авто на главной — улучшили внутреннюю перелинковку.
6. **Репутационная оптимизация**
 - Повысили рейтинг организации в выдаче — довели оценку с 4.2 до 4.3 звезды для улучшения кликабельности в поисковой выдаче.
 - Получили знак проверенного магазина в Поиск по товарам — повысили доверие пользователей к бренду.
7. **Контроль и мониторинг результатов**
 - Настроили систему отслеживания позиций и отслеживали динамику органического трафика.
 - Контролировали данные панелей Яндекс Вебмастер — мониторили технические ошибки и индексацию страниц.
 - Готовили регулярные отчёты с ключевыми показателями роста и корректировали стратегию продвижения на основе полученных данных.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить количество запросов в топ-10 поисковой выдачи — достигли существенного роста небрендовых запросов в первую десятку результатов поиска по автомобильным аккумуляторам.
- Увеличить органический трафик без брендовых запросов на 75% за период с октября 2021 по январь 2024 года.
- Расширить семантическое покрытие — охватили весь спектр запросов в сфере продажи автомобильных аккумуляторов и сопутствующих услуг.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в аккумуляторной нише.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и значительно превысить цель по росту поискового трафика:

- Органический трафик небрендовых запросов увеличился на 75% за период с октября 2021 по январь 2024 года.
- Стоимость привлечения посетителя (CPC) сократилась на 43,3% — с 0,30 до 0,17 рублей при неизменном бюджете.
- 85,92% трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в автомобильной нише.
- Заняты позиции в ТОП-10 Яндекса и Google по ключевым запросам продажи автомобильных аккумуляторов в Москве.

# Поисковое продвижение сайта компании «Ханкс»

«Ханкс» — специализированная сервисная компания, предлагающая комплексные решения в сфере экологии и технического обслуживания для бизнеса. Компания обеспечивает соблюдение экологических норм и чистоту на предприятиях, организуя сбор и переработку отходов, обслуживание инженерных систем и профессиональный клининг для ценителей качества и ответственного отношения к окружающей среде.

Описание работ

1. **Создали новые страницы с текстами**
 - Разработали и запустили более 40 новых страниц для разных услуг: утилизация люминесцентных ламп, очистка жироуловителей, вывоз отработанного масла, дератизация и другие экологические услуги. Подготовили понятные тексты для каждой страницы — описали услуги простым языком, указали цены и условия работы. Написали полезную статью «Документы для открытия ресторана».
2. **Разработали удобный дизайн для всех устройств**
 - Создали современные макеты для ключевых страниц — «Продать отработанное масло», «Очистка жироуловителей», «Контакты» и «Отзывы». Сделали так, чтобы клиенты сразу видели главную информацию и могли легко оставить заявку. Все страницы одинаково хорошо работают на компьютере и телефоне.
3. **Запустили сайт в четырёх регионах**
 - Создали отдельные версии сайта для Санкт-Петербурга, Уфы, Самары и Нижнего Новгорода. Теперь клиенты из этих городов видят актуальную информацию именно для своего региона, что увеличило количество обращений.
4. **Разработали стратегию продвижения**
 - Проанализировали конкурентов и нашли способы сделать сайт заметнее в поиске. Каждый квартал находили новые фразы, по которым клиенты ищут услуги, и оптимизировали под них сайт. Составили пошаговый план развития на несколько месяцев вперёд.
5. **Улучшили работу сайта**
 - Подключили систему онлайн-оплаты ЮKassa — клиенты могут оплачивать услуги прямо на сайте. Регулярно обновляли цены. Настроили корпоративную почту и добавили видеоматериалы для лучшего представления услуг.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить количество запросов в топ-10 поисковой выдачи — достигли существенного роста небрендовых запросов в первую десятку результатов поиска.
- Увеличить органический трафик без брендовых запросов на 402% за период с января 2024 по август 2025 года.
- Расширить семантическое покрытие — охватили весь спектр запросов в сфере экологических услуг, утилизации отходов и обслуживания природоохранного оборудования.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише экологических услуг.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и значительно превысить цель по росту поискового трафика:

- Органический трафик небрендовых запросов увеличился на 402% за период с января 2024 по август 2025 года.
- Стоимость привлечения посетителя (CPC) сократилась на 80% при неизменном бюджете.
- 79,94% трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в нише экологических услуг.
- Заняты лидирующие позиции в Яндексе и Google по ключевым запросам утилизации отходов, очистки жироуловителей и других экологических услуг.

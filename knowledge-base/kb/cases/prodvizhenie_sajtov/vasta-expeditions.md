# Поисковое продвижение сайта компании «Vasta Expeditions»

«Vasta Expeditions» — туристическая компания, специализирующаяся на организации экспедиционных и приключенческих туров в труднодоступные и уникальные регионы России, предлагающая авторские маршруты, активный отдых, исследовательские путешествия и комплексное сопровождение экспедиций.

Перейти на сайт: vasta-expeditions.ru

Продвижение сайтов
Имиджевый сайт

Описание работ

1. **Разработка уникальной структуры страниц**
 - Спроектировали конверсионную структуру коммерческих страниц — вынесли основные преимущества и программу экспедиций в первый экран, чтобы путешественник сразу видел ценность предложения.
 - Создали детальные страницы для каждой активности экспедиционных туров — обеспечили полноту информации для принятия решения о бронировании.
 - Разработали хабовые страницы для основных направлений — Камчатка, Курильские острова, Командорские острова, Чукотка, Приморский край — с чёткой навигацией и релевантным контентом.
 - Создали уникальные страницы по сезонам и месяцам путешествий — теперь турист попадает на релевантную страницу с актуальным расписанием экспедиций.
 - Разработали серию страниц по островам, которые посещаются в ходе экспедиций — остров Ратманова, Шантарские острова и другие ключевые точки маршрутов.
2. **Уникальный контент для экспедиционного туризма**
 - Нашли нестандартный подход — транскрибировали видеоконтент в текстовые статьи, получили уникальный материал и проверили его эффективность для поискового продвижения.
 - Внедрили блоки с информацией о рейтингах в туристических сервисах и справочниках на детальных страницах экспедиций — построили доверие через социальные доказательства.
3. **Специфические оптимизации под бизнес-задачи**
 - Перевели информационные статьи на статичные URL вместо pop-up формата — ускорили индексацию и улучшили структуру блога.
 - Реализовали изменение позиционирования бренда и обновили нейминг на всех страницах сайта.
 - Создали уникальный блок «Острова, которые мы посещаем» с детальными страницами по каждому острову — улучшили навигацию и распределение веса страниц.
 - Импортировали проект в Bing Webmaster Tools — расширили присутствие проекта в дополнительных поисковых системах.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить количество запросов в топ-10 поисковой выдачи — достигли существенного роста небрендовых запросов в первую десятку результатов поиска.
- Увеличить органический трафик без брендовых запросов на 355% за период с мая 2024 по ноябрь 2025 года.
- Расширить семантическое покрытие — охватили весь спектр запросов в сфере экспедиционного туризма, морских круизов и путешествий по Дальнему Востоку России.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише экспедиционных круизов.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и значительно превысить цель по росту поискового трафика:

- Органический трафик небрендовых запросов увеличился на 355% за период с мая 2024 по ноябрь 2025 года.
- Стоимость привлечения посетителя (CPC) сократилась на 78,0% при неизменном бюджете.
- 84,3% трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в нише экспедиционного туризма.
- Заняты лидирующие позиции 1—10 места в Яндексе и Google по ключевым запросам экспедиционных круизов, морских путешествий по Дальнему Востоку и активного туризма на Камчатке, Курильских островах и Чукотке.

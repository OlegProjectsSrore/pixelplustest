# Поисковое продвижение сайта компании «LEDsi»

LEDsi — производственная компания, специализирующаяся на разработке и изготовлении светодиодных светильников для различных сфер применения. Предприятие осуществляет полный цикл работ — от проектирования осветительных систем до поставки оборудования для промышленного, уличного, офисного и специализированного освещения.

Перейти на сайт: led-si.com

Продвижение сайтов
Корпоративный сайт

Описание работ

1. **Расширили охват потенциальных клиентов**
 - Изучили близких конкурентов и выгрузили их семантическое ядро
 - Создали новые страницы по конкурентному анализу
 - Запустили создание массового количества страниц под целевые запросы
 - Определили способы масштабного создания посадочных страниц
2. **Улучшили содержание сайта**
 - Написали уникальные тексты для категорийных страниц — более 150 000 символов контента
 - Оптимизировали мета-теги (Title, Description, H1) для продвигаемых страниц
 - Подготовили информационные статьи и доработали их под LLM и SGE
 - Создали детальные посадочные страницы под конкретные вопросы пользователей
3. **Повысили удобство для покупателей**
 - Разработали макеты отзывов для размещения в портфолио и на главной странице (адаптивные версии для ПК, мобильных и планшетов)
 - Подготовили макеты для страниц филиалов (адаптивные версии)
 - Создали макет страницы «Доставка» с адаптацией для всех устройств
 - Добавили блок с указанием гарантий на страницы продуктов
 - Работали с показателем CTR для повышения кликабельности в выдаче
4. **Оптимизировали техническую часть**
 - Настроили базовую оптимизацию шаблонов тегов и мета-тегов
 - Проанализировали и устранили проблемы с выводом цен на страницах
 - Скорректировали распределение внутреннего ссылочного веса
 - Провели сканирование сайта через Screaming Frog SEO Spider
 - Проверили скорость загрузки в Google Search Console на мобильных устройствах
 - Корректировали robots.txt для оптимальной индексации
5. **Усилили региональные и коммерческие факторы**
 - Настроили региональную привязку сайта
 - Создали отдельные страницы для филиалов
 - Подключили Яндекс.Товары и Google Покупки — настроили и загрузили YML-фиды для показа товаров в специальных разделах поисковиков
 - Оценили полноту хостовых и коммерческих факторов согласно критериям E-E-A-T
6. **Реализовали сервисные страницы**
 - Подготовили техническое задание на создание листингов и детальных страниц экранов
 - Создали сервисные страницы: «Сертификаты», «Оплата», «Доставка»
 - Разработали перелинковку между портфолио, услугами и конфигуратором

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Сайт стал технически оптимизирован и удобнее для пользователей
- Больше людей находят вас через поисковики по коммерческим запросам
- Расширился охват за счёт новых посадочных страниц и контента
- Подключены дополнительные каналы продаж через товарные агрегаторы
- Выстроена система регулярного улучшения и анализа проекта

Такой подход создал прочный фундамент для роста продаж через интернет.

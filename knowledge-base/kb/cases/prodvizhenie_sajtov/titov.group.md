# Поисковое продвижение сайта компании «TITOV GROUP»

«TITOV GROUP» — юридическая компания из Красноярска, специализирующаяся на помощи с банкротством физических лиц и юридическими услугами для клиентов, нуждающихся в списании долгов и сопровождении соответствующих процедур.

Перейти на сайт: titov.group

Описание работ

1. **Техническая оптимизация и устранение критических ошибок**
 - Устранили критические технические ошибки — настроили корректную индексацию, исправили уязвимости Bitrix, восстановили работу форм обратной связи на 94 страницах.
 - Подключили Google Tag Manager для отслеживания конверсий и настроили все системы аналитики. Получили доступы к панелям вебмастеров Яндекс и Google, Яндекс.Метрике и Google Analytics.
 - Заменили доменную зону на .ru для повышения доверия российской аудитории. Ликвидировали ошибки 502 и 503, обеспечив стабильную работу ресурса.
2. **Формирование семантического ядра и стратегии продвижения**
 - Построили семантическое ядро с нуля — собрали семантику из трафиковых страниц конкурентов, разметили близких конкурентов для мониторинга.
 - Загрузили всё в «Пиксель Тулс» и расширяли коммерческое и информационное ядро каждый квартал.
 - Сформировали файл распределения семантики по страницам и настроили систему приоритизации SEO-задач. Провели анализ конкурентов для формирования оптимальной структуры страниц.
3. **Создание и оптимизация страниц услуг**
 - Создали более 60 страниц по ключевым юридическим направлениям — банкротство физических и юридических лиц, регистрация ООО и ИП, ликвидация компаний, юридическое обслуживание бизнеса.
 - Разработали конверсионные структуры для страниц по анализу договоров, составлению договоров, представительству в арбитражном суде, правовой экспертизе, составлению претензий и другим востребованным услугам.
 - Создали страницы с прайс-листами, контактами и сертификатами для повышения доверия клиентов.
4. **Контентная стратегия и текстовая оптимизация**
 - Подготовили технические задания на 40+ страниц в шести партиях, написали и согласовали тексты.
 - Провели рерайт 52 статей конкурентов и создали 18 уникальных материалов для раздела «Блог».
 - Вручную оптимизировали title, description и h1 на всех продвигаемых страницах. Убрали спамные слова со всех страниц сайта. Добавили блоки с ценами, сертификатами и гарантией безопасной сделки.
5. **Внедрение микроразметки и техническая доработка структуры**
 - Внедрили микроразметку schema.org для основных типов страниц — карточек услуг и статей блога. Сниппеты в поиске стали информативнее и привлекательнее для потенциальных клиентов.
 - Создали новое навигационное меню с выпадающими списками для десктопной и мобильной версий. Разработали блоки «Сотрудники» и «Проверено экспертом» для повышения экспертности и доверия.
 - Провели оптимизацию области контента через искусственный интеллект. Улучшили отображение сниппета в выдаче Google путем корректировки метатегов.
6. **Развитие информационного раздела**
 - Сформировали полноценный раздел «Блог» с качественными экспертными материалами. Провели корректировку базовой оптимизации всех информационных страниц.
 - Внедрили микроразметку для статей блога, добавили хлебные крошки для улучшения навигации. Создали страницы кейсов для демонстрации успешных проектов компании.
 - Разработали страницы команды с общей и детальной информацией о сотрудниках. Добавили блок «Сотрудники» на страницы услуг для усиления доверия клиентов.
7. **Аналитика и мониторинг результатов**
 - Настроили глубокую аналитику проекта через «Модуль ведения проектов» системы «Пиксель Тулс». Провели пост-апдейтную аналитику групп URL для оценки влияния обновлений алгоритмов поисковых систем.
 - Регулярно проводили аудит сайта для выявления причин отсутствия роста целевых действий. Осуществляли поиск и проработку малоэффективных и неэффективных страниц в индексе Google.
 - Формировали ежемесячные планы работ и детальные отчёты для клиента с анализом достигнутых результатов и рекомендациями по дальнейшему развитию проекта.

Результат комплексного подхода

За 12 месяцев работы:

- Увеличили трафик в 21,88 раза — рост на 2088% без учёта брендовых запросов.
- Снизили CPC на 95% — с 1 612,07 до 73,68 рубля за посетителя.
- Достигли 98,52% небрендового трафика — сайт привлекает целевую аудиторию по широкому спектру коммерческих запросов.
- Вывели в ТОП-10 ключевые запросы — по юридическим услугам в Красноярске.

Такой системный подход создал прочную основу для устойчивого роста органического трафика в конкурентной нише юридических услуг.

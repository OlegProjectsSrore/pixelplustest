# Продвижение интернет-магазина спортивного оборудования YOUSTEEL, увеличение целевого трафика для сайта (кейс)

Компания YOUSTEEL начала свою деятельность по поставке спортивного оборудования в 2013 году с организации собственного производства функциональных рам для функционального и силового тренинга, не уступающих по качеству зарубежным аналогам.

С ростом CrossFit® сообщества расширялся и ассортимент оборудования для силовой, функциональной, кардио и кондиционной подготовки.

Сегодня YOUSTEEL – это бренд надежного и доступного спортивного оборудования для силового и функционального тренинга.

Цель проекта – увеличение целевого трафика из поисковых систем и общего числа заявок с ресурса.

Для достижения поставленных целей был выполнен комплекс мер:

- сбор и корректировка семантического ядра;
- оптимизацию всех страниц сайта;
- исправлены технические ошибки;
- работа над поведенческими факторами;
- проведены работы по переезду на https-протокол;
- проработаны расширенные сниппеты карточек товаров в поисковой выдаче.

По результатам совместной работы нашей компании и «Юстил» за год сотрудничества удалось увеличить посещаемость сайта по поисковым запросам Московского региона почти в полтора раза.

Сегодня проект занимает лидирующие позиции по продвигаемым запросам.

## Прирост трафика с начала работ по поисковой оптимизации

Трафик из поисковых систем за период ноябрь 2016 года – ноябрь 2017 года вырос на 48%. Абсолютное значение превысило 1 500 переходов в месяц, без учета брендовых запросов.

Распределение трафика по основным каналам

Основной трафик на сайт приходит за счет переходов из рекламы и поисковых систем. Доля с поиска составляет около 50.3%, а именно более 7.5 тысяч переходов в месяц.

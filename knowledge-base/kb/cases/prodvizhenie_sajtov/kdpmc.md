# Поисковое продвижение сайта компании «Детский медицинский центр»

«Детский медицинский центр» Управления делами Президента РФ — многопрофильный медицинский комплекс, оказывающий амбулаторную и стационарную помощь детям. В структуру центра входят поликлиники, санаторно-реабилитационные подразделения и диагностические отделения.

поисковое продвижение

Описание работ

1. **Работали с контентом**
 - Сформировали технические задания на тексты и организовали создание контента для коммерческих страниц услуг, диагностики, МРТ и реабилитации — более 80 URL за период работ.
 - Согласовали написанные материалы и разместили их на продвигаемых страницах сайта.
 - Добавили коммерческие элементы на информационные статьи — блоки с профилями врачей, актуальными ценами и формами записи на приём.
 - Внедрили таблицу цен в шаблон статейных страниц, что усилило их коммерческую составляющую.
 - Заполнили и актуализировали цены на страницах заболеваний по всем ключевым разделам.
 - Выполнили оптимизацию страниц врачей и услуг дневного стационара.
2. **Создавали новые коммерческие разделы**
 - Провели кластеризацию семантики по направлениям: диагностика, УЗИ, МРТ, реабилитация.
 - Определили темы и сформировали структуру для создания коммерческих страниц по анализам, УЗИ-исследованиям и специализированным услугам клиники.
 - Создали новый раздел «Реабилитация» — разработали и разместили 22 URL с полноценным контентом.
 - Создали страницы МРТ-диагностики — разработали макет, верстку и текстовый контент для нового направления.
 - Распределили заболевания по соответствующим страницам услуг для повышения тематической релевантности и охвата смежных запросов.
 - Создали динамическую страницу с прайсом на услуги клиники.
3. **Улучшали навигацию и пользовательский опыт**
 - Создали, сверстали и разместили страницу «Сертификаты».
 - Добавили в мобильное меню страницы второго уровня для улучшения доступности разделов с мобильных устройств.
 - Обновили шаблон карточки врача — добавили новые поля специальности, расширили структуру блока.
 - Разработали и внедрили новый шаблон информационных страниц: с блоком содержания, указанием проверяющего специалиста, разделами с врачами и ценами.
 - Добавили информационную плашку о дневном стационаре в шаблон страниц.
 - Проработали и реализовали новую структуру верхнего меню для ПК и мобильных устройств, перенесли на продакшн.
 - Разработали прототип и макет обновлённой главной страницы.
 - Провели аудит отказов и среднего времени пребывания на сайте, сформировали гипотезы по росту заявок.
4. **Наращивали ссылочный профиль**
 - Увеличили количество входящих ссылок на сайт для укрепления внешнего авторитета домена в нише детской медицины.
5. **Работали с фидами и аналитикой**
 - Настроили и регулярно корректировали YML-фид для Яндекс — добавляли врачей, актуализировали специальности и данные об услугах.
 - Настроили цели в Google Tag Manager для корректного отслеживания конверсий по ключевым сценариям поведения пользователей.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Существенно расширить охват коммерческой семантики за счёт создания новых разделов: МРТ, реабилитация, УЗИ-диагностика, дневной стационар.
- Повысить коммерческую ценность информационных страниц путём добавления цен, врачей и форм записи.
- Улучшить внутреннюю навигацию и пользовательский опыт на ПК и мобильных устройствах.
- Обеспечить устойчивый рост небрендового органического трафика из поисковых систем в 4 раза за два года работ.
- Снизить стоимость привлечения посетителя при неизменном рекламном бюджете.

Такой подход создал прочную основу для дальнейшего масштабирования присутствия сайта в поисковой выдаче по коммерческим и смежным запросам в нише детской и подростковой медицины.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и создать стабильную основу для дальнейшего роста органического трафика:

- Небрендовый органический трафик из поисковых систем увеличился в 4 раза за период с марта 2024 по март 2026 года.
- Стоимость привлечения посетителя (CPC) сократилась на 75,5% при неизменном бюджете — с 3,67 до 0,90 рубля за посетителя.
- 91,14% поискового трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией.
- Заняты лидирующие позиции в Яндексе и Google по ключевым коммерческим запросам в нише детской диагностики, УЗИ-исследований, реабилитации и специализированных медицинских услуг.

# Продвижение медицинского цента cirpp.ru в Москве, раскрутка сайта в ТОП-10 тематике «лечение РПП»

Описание работ

В начале работ по проекту наблюдалась негативная тенденция в Google, а именно с лета 2018 года трафик уменьшился более чем в 4 раза. При этом количество переходов из Яндекса оставалось стабильным.

Проектная SEO-группа провела анализ ситуации в результате которого был сделан вывод, что потеря трафика связана с радикальными изменениями работы Google в отношении YMYL страниц. В августе 2018 года официально объявлено об обновлении его работы, после которого по медицинской тематике значительно изменился ТОП-10.

Исходя из всего этого работы по проекту были подстроены под новые требования Google, при этом нельзя было потерять результат в Яндексе.

Исходя из новых требований, предъявляемые к YMYL страницам, было проведено:

- проработаны коммерческие документы: "О нас", "Контакты" и подобные;
- регулярный контроль работоспособности сайта и его функционала;
- работы для увеличения авторитетности ресурса;
- проработка контента (уникальность, структурированность, доступность для понимания);
- указание авторства статей;
- проработка коммерческих элементов каждой из страницы услуг.

Благодаря комплексному подходу к SEO, количество запросов в ТОП-10 и трафик из поисковых систем показали значительный рост.

Сейчас проект занимает лидирующие позиции среди медицинских сайтов аналогичной тематики, и имеет максимальный охват аудитории по направлению РПП.

## Анализ прироста поискового трафика

Трафик из поисковых систем за период январь — октябрь 2019 года вырос на 290%. В абсолютном значение число визитов увеличилось на более чем 8.5 тысяч переходов в месяц, без брендовых запросов.

На старте работ поисковый трафик из Google снизился на 81% относительно максимума в июле 2018 года. За период январь — октябрь 2019 удалось значительно улучшить ситуацию и практически восстановить количество переходов из поисковой системы. На текущий момент продолжаем вести активные работы с целью дальнейшего увеличения трафика из Google.

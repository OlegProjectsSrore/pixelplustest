# Кейс по увеличению трафика сайта по продаже ювелирных изделий из натурального жемчуга

Компания «DAME» — один из крупнейших поставщиков натурального жемчуга в Россию и интернет-магазин по продаже ювелирных изделий из натурального жемчуга.

Перейти на сайт: dame-gem.ru

Ювелирный

Начало сотрудничества:

ноябрь 2023 года

Основные работы:

поисковое продвижение

Цель:

увеличение небрендового поискового трафика, продвижение в ТОП-10 семантического ядра

**Цель проекта** — увеличение небрендового поискового трафика на сайт в 10 раз, продвижение в ТОП-10 фиксированного списка целевых фраз.

Описание работ

DAME является одним из крупнейших поставщиков натурального жемчуга в Россию, имеет свое производство, сотрудники которого проходят обучение в Японии. Передовая техника изготовления жемчужных нитей основана на ручном труде и использовании только высококачественных материалов.

Проект у нас в поисковом продвижении всего 3 месяца, но уже есть результат. На примере данного кейса показываем, как важно заняться оптимизацией сайта для поисковых систем, чтобы увидеть эффект иногда уже в совсем коротком периоде.

Какие работы мы выполнили:

1. На старте работ был проанализирован текущий потребительский спрос в поисковых системах, выявлена неохваченная семантика, сформировано актуальное семантическое ядро и запущена задача по созданию 20 новых URL.
2. Установлена региональность сайта в Яндекс Вебмастер и Яндекс Бизнес (регион продвижения — Москва).
3. Внедрена микроразметка страниц.
4. Выявлены и устранены ошибки влияющие на релевантность страниц. А именно:
 - повторяющиеся скрытые формы;
 - множественные вхождения не ключевых слов в блоках характеристик в карточках на листингах товаров;
 - скрыли от поисковых систем большой объем текстового контента на страницах категорий для исключения влияния его на релевантность страниц по ключевым запросам (в частности, блок раздела «Блог» с развернутыми анонсами статей).
5. Найдены и устранены критические для всего сайта технические ошибки.

Итог

Специалистам компании «Пиксель Плюс» уже на старте работ удалось увеличить поисковый трафик на сайт:

- поисковый трафик за 3 месяца работ вырос на 32%, без учета брендовых запросов;
- CPC сократилась на 24,06% до 3,85 рубля/посетитель;
- в ТОП-10 ПС Яндекс находится 46% целевых запросов и 59% — в ТОП-10 Google.

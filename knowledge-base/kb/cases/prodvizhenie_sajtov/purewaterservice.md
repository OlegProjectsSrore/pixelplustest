**Цель проекта** — рост поискового трафика за счёт эффективного SEO и оптимизации сайта.

Описание работ

Для достижения цели были реализованы работы по всем ключевым направлениям SEO: семантика, контент, техническая и внутренняя оптимизация, улучшение структуры сайта и аналитика.

Какие работы мы выполнили:

1. Работа с семантическим ядром и контентом:

- проводили ежеквартальное расширение семантического ядра для охвата новых поисковых ниш;
- сформировали файл распределения и повысили релевантность страниц ключевым запросам;
- создали информационные страницы и статьи для привлечения дополнительного трафика.

2. Техническая оптимизация:

- устранили критические ошибки, мешавшие индексации сайта;
- настроили корректные редиректы для страниц с ошибками 404 и другими проблемами.

3. On-page оптимизация:

- выполнили комплексную on-page оптимизацию, включая теги, заголовки и структуру контента;
- ручная оптимизация title, description и H1 на основе запросов и анализа конкурентов;
- оптимизировали листинги и коммерческие страницы для повышения конверсии.

4. Работа с карточками товара:

- уникализировали описания товаров для улучшения позиций в поиске;
- дополняли карточки характеристиками, отзывами и полезной информацией;
- добавили блоки о доставке и оплате для повышения поведенческих факторов.

5. Проработка коммерческих факторов:

- создали новые коммерческие страницы для продвижения по высокочастотным запросам;
- подключили Яндекс Товары и Google Покупки для привлечения товарного трафика;
- расширили коммерческое семантическое ядро для увеличения охвата.

6. Оптимизация структуры:

- внедрили теговую перелинковку для улучшения внутренней структуры сайта;
- оптимизировали сортировку товаров для повышения удобства и улучшения поведенческих факторов;
- добавили блоки FAQ в каталоги для повышения релевантности категорийных страниц.

7. Мониторинг и аналитика:

- анализировали динамику небрендового органического трафика и корректировали стратегию;
- выявляли страницы с потерей трафика и проводили работы по их восстановлению;
- настроили цели в аналитике для отслеживания конверсий и оценки эффективности SEO.

Работы по проекту проводились системно и последовательно, с упором на качество, устойчивый рост и адаптацию к изменениям в алгоритмах поисковых систем.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и значительно превысить цель по росту поискового трафика:

- Максимальный рост трафика — за период с мая 2024 по май 2025 трафик увеличился почти в 3,8 раза (+278%).
- Стоимость привлечения посетителя (CPC) сократилась на 73,6% — с 91,28 до 24,15 рублей.
- Поисковый трафик составляет 66,94% от всего трафика сайта, демонстрируя уверенное доминирование в выдаче.
- 99,68% трафика приходится на общие тематические запросы, что подтверждает точную работу с целевой аудиторией.
- Доля брендовых запросов снижена с 13,1% до 0,32%, что обеспечивает независимость от узнаваемости бренда.
- При неизменном бюджете достигнуто почти 4-кратное увеличение трафика, что подтверждает высокую экономическую эффективность проекта.

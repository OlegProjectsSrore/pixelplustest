# Поисковое продвижение сайта компании «Техстрой»

«Техстрой» — компания, занимающаяся поставкой нерудных строительных материалов, абразивов и противогололедных реагентов. В ассортимент входят кварцевый песок, щебень, декоративные материалы и продукция для строительных и промышленных работ.

Перейти на сайт: teh-stroy.ru

Продвижение сайтов
Интернет-магазин

Описание работ

1. **Работали с контентом**
 - Написали SEO-тексты для целевых страниц и разместили их на сайте после согласования с клиентом.
 - Подготовили описания для карточек товаров по ключевым разделам: кварцевый песок, дробь стальная, купершлак, гравий, противогололедные материалы — суммарно более 120 страниц.
 - Обновили тексты разделов под актуальные коммерческие запросы, разместили отзывы на товары.
2. **Расширяли и чистили семантику**
 - Собрали семантику по конкурентам, распределили запросы по страницам сайта.
 - Трижды расширяли семантическое ядро в течение проекта — добавили новые коммерческие запросы и проработали под них посадочные страницы.
 - Очистили ядро от нерелевантных и дублирующихся запросов.
3. **Устраняли технические проблемы**
 - Устранили уязвимость CMS «Битрикс» на старте проекта.
 - Настроили robots.txt, canonical и 301-редиректы — убрали дубли страниц из индекса.
 - Исправили битые ссылки, настроили корректный код 404 для несуществующих страниц пагинации.
 - Внедрили микроразметку schema.org для товаров, листингов и фильтровых страниц.
 - Провели переобход 398 URL в Google Search Console — ускорили индексацию обновлённых страниц.
 - Обновили счётчики аналитики, продлили SSL-сертификат.
4. **Развивали структуру каталога**
 - Создали более 60 фильтровых и теговых страниц под высокочастотные и среднечастотные запросы.
 - Загрузили более 200 карточек товаров по разделам, заполнили характеристики и свойства для корректной работы фильтров.
 - Настроили ЧПУ и шаблоны мета-тегов для фильтровых страниц и пагинации.
 - Удалили устаревшие карточки, настроили редиректы со старых URL.
 - Добавили в карточки ссылки на альтернативную упаковку и блок «Похожие товары».
5. **Улучшали пользовательский опыт**
 - Вручную оптимизировали title, description, h1 для продвигаемых страниц.
 - Исправили ошибки в мобильной версии сайта, скорректировали отображение таблиц в блоге.
 - Разместили баннеры с акциями, сертификаты, стикеры «Хит продаж» и «Скидка» с ценами.
 - Внедрили внутреннюю перелинковку для усиления приоритетных страниц.
 - Удалили теги <noindex>, скрывавшие контент от поисковых роботов.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Устранить технические ошибки, мешавшие индексации сайта.
- Расширить охват семантики за счёт фильтровых и теговых страниц.
- Наполнить каталог карточками товаров с описаниями, характеристиками и отзывами.
- Улучшить пользовательский опыт на мобильных устройствах и десктопе.
- Обеспечить устойчивые позиции в ТОП-10 Яндекса и Google по целевым запросам.

Такой подход создал прочный фундамент для стабильного роста поискового трафика и увеличения количества заявок через органический поиск.

# Поисковое продвижение сайта компании «Autostet»

«Autostet» — автошкола, предоставляющая обучение вождению по различным категориям транспортных средств. Обучение включает теоретическую подготовку и практические занятия с инструкторами на учебных автомобилях, с последующим допуском к экзаменам в ГИБДД.

Перейти на сайт: auto-stet.ru

Продвижение сайтов
Корпоративный сайт

Описание работ

1. **Расширяли структуру сайта**
 - Запустили массовое создание страниц по районам, метро и округам Москвы — охвачено 72 URL.
 - Создали страницу «Автошкола рядом со мной» с картой точек подачи автомобилей с инструкторами.
 - Запустили раздел «Блог» и новый раздел по дополнительному профессиональному образованию (ДПО) — собрали семантику, разработали макеты, опубликовали первые материалы.
2. **Работали с контентом**
 - Разработали и внедрили новый шаблон страниц услуг — для ПК и мобильных устройств.
 - Написали тексты, сформировали Title, Description и H1 для 13 страниц услуг на новом шаблоне.
 - Подготовили контент для блоков «Как добраться», «Преимущества» и «Автоинструкторы» на страницах обучения по территориям.
3. **Улучшали коммерческие страницы**
 - Разработали и внедрили обновлённый макет страницы цен — привязали тарифы к страницам услуг, провели on-page оптимизацию.
 - Добавили оба филиала автошколы на Яндекс Карты и подключили услуги в поиске Яндекса через YML-фиды.
4. **Анализировали и искали точки роста**
 - Провели аудит сайта для выявления причин отсутствия роста целевых действий и запустили юзабилити-аудит через систему-партнёр «Askusers».

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Существенно расширить охват локальной семантики по районам и округам Москвы.
- Сформировать новые точки входа из поиска — ДПО, «Блог», страница с картой.
- Усилить коммерческие страницы и улучшить пользовательский опыт.
- Обеспечить устойчивый рост небрендового органического трафика из поисковых систем.

Такой подход создал прочный фундамент для дальнейшего масштабирования присутствия сайта в поисковой выдаче по коммерческим запросам в нише автошкол и обучения вождению.

За период работ (январь 2024 — июль 2025 года) поисковый трафик без брендовых запросов вырос на 976%, в 10,8 раза.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и создать стабильную основу для дальнейшего роста органического трафика:

- Небрендовый органический трафик из поисковых систем увеличился в 10,8 раза за период с января 2024 по июль 2025 года.
- Стоимость привлечения посетителя (CPC) сократилась на 90,7% при неизменном бюджете — с 1 352,64 до 125,66 рубля за посетителя.
- 72,5% поискового трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией.
- Заняты лидирующие позиции в Яндексе по коммерческим запросам: «автошкола акпп москва» — 6-е место, «автошкола в Северном Бутово» — 7-е, «категория а обучение» — 8-е, «автошкола бауманская» и «автошкола в САО» — 9-е.

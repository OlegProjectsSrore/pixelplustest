# Поисковое продвижение сайта компании «1Kargo»

«1Kargo» — транспортно-логистическая компания, специализирующаяся на доставке грузов из Китая в Россию. Предоставляет комплексные услуги, включая перевозку различными видами транспорта, таможенное оформление, поиск поставщиков и сопровождение сделок.

Описание работ

1. **Выстраивали ссылочный профиль сайта**
 - Ежемесячно подбирали тематические площадки и закупали внешние ссылки с написанием авторских статей.
 - На протяжении всего периода работ последовательно формировали группы продвигаемых URL в системе аналитики для контроля динамики роста позиций.
2. **Создавали и расширяли коммерческие посадочные страницы**
 - Обеспечили планомерное создание новых страниц услуг: ежемесячно размещали оптимизированный контент партиями по 5–7 URL.
 - Создали посадочную страницу «Доставка в белую с оптимизацией», ориентированную на сегмент B2B.
 - Запустили работы по созданию страницы «Доставка из Китая в Москву» с учётом регионального спроса.
 - Добавили таблицы с ценами и тарифами на ключевые страницы услуг для повышения конверсионности.
 - Запустили создание новых информационных страниц для охвата смежных поисковых запросов.
3. **Адаптировали позиционирование сайта под новую бизнес-стратегию**
 - Откорректировали теговые вхождения: к ключевым словам «карго», «cargo» и «kargo» добавили уточнения «в белую» и «белая» для соответствия целевой аудитории.
 - Согласовали с клиентом и разместили на сайте информацию о работе исключительно с юридическими лицами.
 - Подготовили техническое задание, провели оценку и внедрили новый макет хедера и слайдера с баннерами, включающего блок услуг «доставка в белую».
 - Подключили Яндекс.Товары и Google Покупки — настроили и загрузили YML-фиды в Яндекс.Вебмастер и Google Merchant Center.
4. **Анализировали поведение пользователей и выявляли точки роста**
 - Провели юзабилити-аудит на платформе «Askusers» и обработали результаты для формирования задач по улучшению пользовательского опыта.
 - Проанализировали поведение посетителей с помощью сервиса «Вебвизор» Яндекс.Метрики.
 - Выявили и исследовали причины высоких показателей отказов по каналу прямых переходов.
 - Провели конкурентный анализ и определили точки роста по логистическим направлениям, не связанным с Китаем.
 - Выполнили расширенный конверсионный аудит.
 - Регулярно анализировали динамику небрендового органического трафика и показатель конверсии.
5. **Выполняли технические доработки и обеспечивали стабильность сайта**
 - Настроили корректную региональную привязку сайта.
 - Удалили внутренние ссылки с кодом ответа 404 и заменили ссылки с 301-редиректами на прямые.
 - Устранили критические инциденты с работоспособностью сайта: восстановили работу калькулятора расчёта стоимости доставки, ликвидировали последствия взлома и вымогательства.
 - Создали новый источник Турбо-страниц для охвата мобильной аудитории в Яндексе.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Обеспечить последовательное наращивание ссылочного профиля и повышение авторитетности домена в обеих поисковых системах.
- Расширить охват коммерческой семантики за счёт создания новых целевых страниц услуг с учётом регионального и отраслевого спроса.
- Переориентировать сайт на B2B-аудиторию и закрепить позиционирование в нише легальной («белой») доставки из Китая.
- Улучшить конверсионные показатели сайта по результатам юзабилити-аудита и анализа поведенческих данных.
- Обеспечить устойчивый рост небрендового органического трафика из поисковых систем.

Такой подход создал прочный фундамент для дальнейшего масштабирования присутствия сайта в поисковой выдаче по коммерческим запросам в нише грузоперевозок и логистики из Китая.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и создать стабильную основу для дальнейшего роста органического трафика:

- Небрендовый органический трафик из поисковых систем увеличился на 671% за период с января 2024 по март 2026 года — рост в 7,7 раза.
- Стоимость привлечения посетителя (CPC) сократилась на 87,1% при неизменном бюджете — с 22,15 до 2,87 рубля за посетителя.
- 89,09% поискового трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией.
- Заняты лидирующие позиции в Яндексе и Google по ключевым коммерческим запросам в нише международной логистики, грузоперевозок из Китая и сопутствующих услуг.

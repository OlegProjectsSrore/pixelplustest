# Продвижение сайта дверей Porta prima, кейс по продвижению интернет-магазина межкомнатных дверей по Москве

Магазин дверей фабрики Porta prima представляет более 300 моделей, сочетающих в себе высокое качество, изысканный дизайн и современные технологии. Осуществляется продажа и установка изделий собственного производства компании. На сайте каждый сможет купить двери подходящего вида, стиля и цветового решения.

Цель проекта — вывод в ТОП-10 поисковых систем заданных высокочастотных запросов, увеличение целевого трафика.

Сотрудничество с компанией Porta prima началось с независимого SEO-аудита и продолжилось по продвижению сайта в ТОП-10 поисковой выдачи. За время активных работ, с февраля 2018 года, осуществлялось сопровождение подготовки новой версии сайта и далее ее регулярное улучшение для достижения ключевых целей проекта — рост поискового трафика и ТОП-10 по самым конкурентным запросам в тематике.

В числе ключевых работ по проекту: технические аудиты и оптимизация скорости загрузки сайта, работа с адаптивной версией, коммерческие аудиты, ежемесячные работы по повышению юзабилити и внедрению нового функционала для повышения внутрихостовых характеристик, улучшение листингов и карточек товара, оптимизация процесса покупки на сайте.

Проработка под большой пул запросов позволила кратно увеличить видимость и поисковый трафик. На текущий момент упор сделан на самые конкурентные ключи в тематике, сайт вышел в ТОП-10 Яндекса по запросам: [межкомнатные двери], [двери межкомнатные], [раздвижные межкомнатные двери].

Итог

С начала работ по проекту удалось реализовать большой пул работ по поисковой оптимизации, которые позволили достичь поставленных перед нами задач:

- продвинуть в ТОП-10 Яндекса приоритетные и целевые для клиента запросы, такие как [двери межкомнатные] – 7 место, [раздвижные межкомнатные двери] – 4 место;
- увеличить поисковый трафик на 451%, без учета брендовых запросов;
- сократить CPC почти в 6 раз, до уровня 4,32 рубля/посетитель.

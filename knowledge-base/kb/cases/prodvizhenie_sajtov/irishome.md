# Поисковое продвижение сайта компании «Irishome»

IrisHome — российский производитель качественного текстиля и декора для дома. Предлагает стильные и доступные решения для спальни, гостиной и кухни как частным, так и корпоративным клиентам.

поисковое продвижение

Цель:

увеличение небрендового поискового трафика на сайт

Описание работ

1. **Техническая настройка и оптимизация**
 - Выполнили комплексный технический аудит сайта интернет-магазина — устранили критические ошибки индексации и базовые уязвимости CMS Bitrix.
 - Настроили базовую оптимизацию шаблонов мета-тегов и исправили проблемы с выводом цен на страницах сайта.
 - Подключили Яндекс Товары — настроили YML-фиды для интеграции товарных предложений.
 - Провели диагностику на фильтры поисковых систем и настроили региональную привязку сайта.
2. **Конкурентный анализ и создание страниц**
 - Провели анализ конкурентов и их трафиковых страниц — выполнили выгрузку семантического ядра по конкурентам.
 - Определили способы массового создания оптимизированных страниц для покрытия широкого спектра поисковых запросов.
 - Разработали шаблоны автоматизированного создания посадочных страниц и внедрили структурированные данные Schema.org.
3. **Контентная оптимизация**
 - Создали SEO-оптимизированный контент для ключевых коммерческих страниц.
 - Оптимизированы тексты под популярные и средней частотности поисковые запросы по премиум-постельному белью.
 - Внедрили ключевые фразы и LSI-синонимы для расширения семантического покрытия.
4. **Техническая оптимизация производительности**
 - Оптимизировали скорость загрузки страниц и улучшили показатели Core Web Vitals.
 - Выстроили логическую структуру внутренней перелинковки для равномерного распределения ссылочного веса.
 - Настроили мониторинг позиций и систему веб-аналитики для отслеживания результатов.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Значительно улучшить позиции в Google по высокочастотным коммерческим запросам — достичь 1-й позиции по ключевому запросу «постельное белье премиум класса» с частотой 462 запроса в месяц.
- Занять лидирующие позиции по широкому спектру коммерческих фраз в Google — получить 119 запросов в ТОП-10 из 452 продвигаемых (26% от общего семантического ядра).
- Обеспечить высокую видимость по запросам премиум-сегмента — закрепиться на 1-й позиции Google по таким фразам, как «купить постельное белье премиум класса», «постельное белье премиум качества».
- Создать прочную техническую основу для дальнейшего роста органического трафика и масштабирования присутствия в поисковых системах.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика и улучшения позиций в поисковых системах.

Итог

За 7 месяцев работ над проектом нашим специалистам удалось достичь поставленных целей:

- Достигнуть высокой видимости в Google — 26% от всех продвигаемых запросов попали в ТОП-10 поисковой выдачи, что демонстрирует высокую эффективность проведённой оптимизации для конкурентной тематики.
- Занять лидирующие позиции по коммерческим запросам премиум-сегмента — получили 1-е места в Google по ключевым фразам «постельное белье премиум класса», «купить постельное белье премиум качества», что критично для привлечения платёжеспособной аудитории.
- Обеспечить стабильные позиции по нишевым запросам в Яндексе — вывели в ТОП-10 специализированные фразы, формируя экспертность в технических характеристиках товаров и создав основу для дальнейшего роста.
- Создать техническую основу для масштабирования — выполнили 135 задач по оптимизации, что обеспечило стабильный фундамент для дальнейшего роста поискового трафика и расширения присутствия в обеих поисковых системах.

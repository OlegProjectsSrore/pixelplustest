# Поисковое продвижение сайта компании «Aurumex»

«Aurumex» — компания, занимающаяся продажей и выкупом инвестиционных монет из золота и серебра, а также консультированием в сфере инвестиций в драгоценные металлы.

Перейти на сайт: aurumex.ru

Продвижение сайтов
Интернет-магазин

Начало сотрудничества:

сентябрь 2023 года

Основные работы:

поисковое продвижение

Цель:

увеличение небрендового поискового трафика на сайт

Описание работ

1. **Технический аудит и настройка**
 - Выполнили комплексный технический аудит сайта — просканировали структуру и выявили критические технические ошибки, влияющие на индексацию и ранжирование.
 - Устранили базовые технические проблемы с помощью системы «Пиксель Тулс» — исправили ошибки серверных ответов, настроили корректные редиректы и оптимизировали внутреннюю перелинковку.
 - Настроили региональную привязку сайта и цели для отслеживания конверсий, получили доступы к панелям вебмастера Яндекс.
2. **Мета-теги и техническая оптимизация**
 - Сформировали оптимизированные Title и Description для всех продвигаемых страниц — создали уникальные мета-теги с включением ключевых фраз по инвестиционным монетам.
 - Оптимизировали структуру заголовков H1—H6 и внедрили микроразметку Schema.org для улучшения сниппетов в поисковой выдаче.
3. **Расширение ассортимента и функционала**
 - Добавили карточки товаров, которых нет в наличии, но которые дилер готов выкупить — удвоили и утроили ассортимент на страницах листингов.
 - Реализовали функционал кнопки "Купить" на миниатюрах товаров в листингах — при клике товар добавляется в корзину.
 - Разработали и внедрили функционал сравнения товаров — важная возможность для принятия решения о покупке монет.
 - Вывели характеристики монет в миниатюру — пользователь получает максимум информации уже на странице листинга, дополнительные характеристики открываются при наведении курсора.
4. **Контентная оптимизация**
 - Создали продвигаемые страницы и публиковали SEO-контент регулярными партиями на протяжении 12 месяцев — обеспечили постоянный рост объёма оптимизированного контента.
 - Сформировали и загрузили семантическое ядро в систему «Пиксель Тулс» — определили целевые поисковые запросы для каждой страницы по тематике инвестиционных монет.
 - Написали тексты для страниц листингов с помощью ИИ-генератора — собрали структуру через анализ конкурентов, сгенерировали тексты по ТЗ и передали редакторам на вычитку и "очеловечивание".
 - Проработали карточки товаров — разработали функционал вывода графиков исторической цены металла, цены монеты на бирже, стоимости продажи и покупки.
 - Открыли для индексации описания монет с официального сайта Центробанка — информация стала доступна по исходному коду, что усилило растущий тренд видимости карточек.
5. **Создание информационных страниц**
 - Создали страницу с котировками золота в реальном времени — предоставили инвесторам актуальную информацию для принятия решения о покупке.
 - Создали раздел "Блог" с информационными статьями и новостями — охватили информационные запросы об инвестициях в монеты и золото.
6. **Внутренняя перелинковка**
 - Настроили контекстную перелинковку с помощью нейросети — разместили ссылки с уникальными анкорами в виде продвигаемых фраз на страницах статей и новостей.
 - Обогатили анкорную составляющую — проставили ссылки на ключевые разделы с естественными анкорами для усиления внутренней структуры сайта.
7. **Конкурентный анализ**
 - Провели анализ конкурентов в нише инвестиционных монет — выявили топ-игроков рынка и изучили их стратегии продвижения.
 - Нашли новые точки роста на основе анализа рынка — выявили перспективные запросы по инвестиционным монетам, не охваченные конкурентами.
8. **Контроль и мониторинг результатов**
 - Настроили систему отслеживания позиций и отслеживали динамику органического трафика.
 - Готовили регулярные отчёты с ключевыми показателями роста и корректировали стратегию продвижения на основе полученных данных.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить количество запросов в топ-10 поисковой выдачи — достигли существенного роста небрендовых запросов в первую десятку результатов поиска.
- Увеличить органический трафик без брендовых запросов на 594% за период с ноября 2023 по ноябрь 2024 года.
- Расширить семантическое покрытие — охватили весь спектр запросов в сфере инвестиционных монет и драгоценных металлов.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише инвестиционных монет.

Итог

Специалистам компании удалось не только выполнить поставленные клиентом задачи, но и значительно превысить цель по росту поискового трафика:

- Органический трафик небрендовых запросов увеличился на 594% за период с ноября 2023 по ноябрь 2024 года.
- Стоимость привлечения посетителя (CPC) сократилась на 86,0% — с 35,06 до 5,13 рублей при неизменном бюджете.
- 98,31% трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в нише инвестиционных монет.
- Заняты лидирующие позиции 1—10 места в Яндексе и Google по ключевым запросам инвестиционных монет.

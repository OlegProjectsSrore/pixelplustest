# Поисковое продвижение сайта компании «FOX Property»

«FOX Property» — компания, занимающаяся подбором элитной недвижимости в Москве и Московской области и сопровождением сделок, помогая клиентам находить подходящие объекты и проходить все этапы покупки или продажи.

Перейти на сайт: foxproperty.ru

Описание работ

1. **Техническая оптимизация и устранение критических ошибок**
 - Устранили критические технические ошибки — закрыли от индексации тестовые поддомены, исправили дубли заголовков на 274 страницах, настроили автоматическую генерацию мета-тегов.
 - Подключили Google Tag Manager для отслеживания конверсий и настроили все системы аналитики. Провели сканирование через Screaming Frog для выявления структурных проблем.
2. **Формирование семантического ядра и стратегии продвижения**
 - Построили семантическое ядро с нуля — собрали семантику из трафиковых страниц конкурентов, разметили близких конкурентов для мониторинга.
 - Загрузили всё в «Пиксель Тулс» и расширяли ядро каждый квартал. Охватили максимум запросов по коттеджным поселкам, шоссе и населённым пунктам Подмосковья.
3. **Создание и оптимизация страниц коттеджных поселков**
 - Создали более 160 страниц коттеджных поселков для всех ключевых направлений — Новая Рига, Рублёвка, Калужское, Киевское, Минское шоссе.
 - Каждый поселок получил детальное описание с актуальной информацией об инфраструктуре, локации и ценах. Разработали страницы для продажи домов, участков и таунхаусов в конкретных локациях.
4. **Контентная стратегия и текстовая оптимизация**
 - Написали множество контента — подготовили ТЗ на 200+ страниц, написали и согласовали тексты для поселков, переработали 40 устаревших описаний.
 - Разметили тексты структурированными блоками для улучшения восприятия. Добавили страницы «Оплата» и «Выгодные условия по ипотеке».
 - Вручную оптимизировали title, description и h1 на 280 страницах.
5. **Внедрение микроразметки и техническая доработка структуры**
 - Внедрили микроразметку schema.org для карточек объектов — сниппеты в поиске стали информативнее и привлекательнее.
 - Разработали новый футер с правильной перелинковкой для десктопной и мобильной версий. Расставили canonical для устранения дублей контента, восстановили пропавшие тексты.
6. **Стратегия внешнего продвижения**
 - Реализовали стратегию внешнего продвижения — закупили качественные ссылки на тематических ресурсах и распределили ссылочную массу через «Пиксель Тулс».
7. **Аналитика и мониторинг результатов**
 - Настроили глубокую аналитику: подключили Яндекс.Товары и Google Покупки, запустили юзабилити-аудит через «Askusers».
 - Провели пост-апдейтную аналитику для оценки влияния обновлений алгоритмов.

Результат комплексного подхода

За 16 месяцев работы:

- Увеличили трафик в 2,68 раза — рост на 168% без учёта брендовых запросов.
- Снизили CPC на 63% — с 11,62 до 4,34 рубля за посетителя.
- Достигли 94,21% небрендового трафика — сайт привлекает целевую аудиторию по широкому спектру коммерческих запросов.
- Вывели в ТОП-10 ключевые запросы — по коттеджным поселкам и элитным направлениям Подмосковья.

Такой системный подход создал прочную основу для устойчивого роста органического трафика в конкурентной нише загородной недвижимости.

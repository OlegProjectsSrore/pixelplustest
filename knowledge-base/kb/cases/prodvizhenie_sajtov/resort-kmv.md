# Поисковое продвижение сайта компании «Resort-KMV»

Resort-KMV — сервис по подбору и бронированию санаториев Кавказских Минеральных Вод по городу, профилю лечения, уровню сервиса и стоимости путёвки.

Перейти на сайт: resort-kmv.ru

Продвижение сайтов
Корпоративный сайт

Начало сотрудничества:

октябрь 2024 года

Основные работы:

поисковое продвижение

Цель:

увеличение небрендового поискового трафика на сайт

Описание работ

1. **Расширили листинги санаториев по городам**
 - Увеличили количество отображаемых карточек санаториев на страницах основных городов, сделав листинги более полными для пользователей.
 - Результат: видимость в Google выросла с 75,7% до 95,9%, доля запросов в ТОП-10 удержалась на уровне 97%; видимость в Яндексе выросла с 29,2% до 40,1%, доля запросов в ТОП-10 увеличилась с 78% до 87%.
2. **Создали новые посадочные страницы по заболеваниям**
 - Разработали и запустили 255 новых страниц — каждая посвящена подбору санаториев для лечения конкретного заболевания, что позволило охватить большой пласт низко- и среднечастотных коммерческих запросов.
 - Результат: видимость в Google выросла с 0% до 100%, доля запросов в ТОП-10 — с 6% до 74%; видимость в Яндексе выросла с 0% до 85%, доля запросов в ТОП-10 — с 4% до 100%.
 - Новые страницы уже в первые месяцы принесли 566 органических визитов и 9 конверсий при показателе отказов 6,18% и среднем времени на сайте 2 минуты 51 секунда.
3. **Разработали страницы с рейтингами санаториев по звёздности**
 - Создали отдельные посадочные страницы с подборками санаториев по категории звёздности (3, 4 и 5 звёзд) под запросы, связанные с поиском санатория определённого уровня сервиса.
 - Результат: видимость в Google выросла с 12,4% до 28,4%, доля запросов в ТОП-10 — с 40% до 68%; видимость в Яндексе выросла с 3,5% до 6,4%, доля запросов в ТОП-10 — с 13% до 60%.

Результат комплексного подхода

Комплексное расширение структуры сайта позволило:

- Существенно нарастить количество запросов в ТОП-10 и ТОП-3 поисковых систем.
- Закрыть крупный пласт низко- и среднечастотных коммерческих запросов за счёт страниц по заболеваниям.
- Сделать листинги городов более полными и удобными для выбора санатория.
- Расширить охват выдачи по запросам, связанным с уровнем сервиса санаториев.
- Получить целевой органический трафик и конверсии уже в первые месяцы после запуска новых страниц.

Такой подход создал прочный фундамент для дальнейшего масштабирования присутствия сайта в поисковой выдаче по коммерческим запросам в нише подбора и бронирования санаториев КМВ.

Итог

Специалисты компании сосредоточились на системном расширении структуры сайта:

- Увеличили количество карточек санаториев в листингах городов.
- Создали более 250 новых посадочных страниц по конкретным заболеваниям.
- Разработали страницы с подборками санаториев по категориям звёздности.
- Обеспечили рост количества запросов в ТОП-10 с 463 до 1840 за период январь–сентябрь 2025 года.
- Новые страницы уже в первые месяцы начали приносить целевой органический трафик и конверсии.

Такой подход создал прочный фундамент для стабильного роста поискового трафика и увеличения количества заявок через органический поиск.

# Поисковое продвижение сайта компании «Рекат»

«Рекат» — научно-производственная компания, занимающаяся бестраншейным ремонтом трубопроводов. Применяемая технология позволяет восстанавливать сети методом создания композитного слоя внутри трубы без вскрытия грунта.

Перейти на сайт: rekat.org

Корпоративный сайт
Строительство

Начало сотрудничества:

февраль 2018 года

Основные работы:

поисковое продвижение

Цель:

увеличение небрендового поискового трафика на сайт

Описание работ

1. **Работали над видимостью страниц в поиске**
 - Провели on-page оптимизацию продвигаемых страниц с учётом анализа пар «запрос — URL» и поведенческих факторов ранжирования.
 - Провели работы по улучшению показателя CTR — скорректировали description для целевых страниц, чтобы повысить кликабельность в результатах поиска.
 - Проработали сниппеты посадочных страниц под частотные коммерческие запросы.
 - Написали уникальный SEO-текст для страницы о бестраншейной канализации под целевые коммерческие запросы.
 - Выстроили перелинковку со страниц статей на страницы услуг для усиления ссылочного веса продвигаемых разделов.
 - Актуализировали даты публикаций на страницах статей.
2. **Развивали коммерческие факторы и доверие к сайту**
 - Провели оценку полноты хостовых и коммерческих факторов ранжирования, а также E‑E‑A‑T критериев — и последовательно внедрили рекомендации по их улучшению.
 - Создали страницу «Оплата» и разместили реквизиты компании для соответствия критериям коммерческого ранжирования.
 - Добавили федеральный номер телефона и запросили цены на услуги в формате «от» для размещения на целевых страницах.
 - Добавили к отзывам даты их оставления для повышения доверия к блоку отзывов.
 - Разместили сканы благодарственных писем и отзывы от B2B- и B2C-компаний на страницах сайта.
 - Заменили разрешительную документацию на актуальную.
3. **Работали с региональными сигналами**
 - Установили регион в кабинете Яндекс.Бизнеса и скорректировали геопривязку проекта.
 - Разместили отзывы в карточку Яндекс.Справочника для усиления позиций в локальном поиске.
 - Скорректировали статус работы компании в карточке Яндекс.Карт.
4. **Устраняли технические проблемы**
 - Обнаружили и устранили проблему долгого ответа сервера, которая негативно сказывалась на индексации и поведенческих факторах.
 - Настроили 301-редиректы для страниц с множественным слешем — устранили технические дубли из индекса поисковых систем.
 - Удалили страницы с кодом ответа 404 из структуры сайта.
 - Восстановили корректную работу формы «Оставить заявку» на страницах услуг и кнопки «Отправить» в форме «Задать вопрос».
 - Провели снятие пост-фильтра, оказывавшего негативное воздействие на ранжирование продвигаемых страниц.
 - Добавили файл favicon в формате SVG по рекомендациям Яндекса.
 - Обеспечили своевременное продление SSL-сертификата сайта.
5. **Анализировали конкурентов и искали точки роста**
 - Провели анализ конкурентов, определили точки роста и поставили задачи на их основании.
 - Собрали первичную семантику по фиксированному списку URL конкурентов и согласовали её с клиентом.
 - Провели аудит поведенческих факторов ранжирования и сформировали ТЗ на повышение вовлечённости пользователей по наиболее частотным парам «запрос — URL».
6. **Улучшали пользовательский опыт на мобильных устройствах**
 - Разработали и реализовали макет закреплённой шапки сайта для мобильных устройств.
 - Реализовали обновлённый макет блока услуг для страницы «Технологии санации трубопровода» на мобильных устройствах.
 - Внедрили блок «Этапы работ» и блок перелинковки на страницы услуг.
 - Заменили статичное изображение карты на интерактивный виджет.
 - Провели корректировки вёрстки сайта для мобильной версии.
 - Повышали скорость загрузки страниц сайта.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Устранить технические ошибки, мешавшие корректной индексации и снижавшие скорость загрузки страниц
- Усилить коммерческие и поведенческие факторы ранжирования за счёт проработки контента и структуры страниц
- Улучшить кликабельность сниппетов и нарастить поисковый трафик без увеличения рекламного бюджета
- Повысить доверие к сайту за счёт размещения актуальной документации, отзывов и коммерческой информации
- Обеспечить устойчивые позиции в ТОП-10 Яндекса и Google по целевым коммерческим запросам в тематике санации трубопроводов

Такой подход создал прочный фундамент для стабильного роста поискового трафика и увеличения количества заявок через органический поиск.

Итог

Специалистам компании удалось выполнить поставленные задачи и обеспечить устойчивый рост поискового трафика:

- Органический трафик небрендовых запросов увеличился на 105% за период с декабря 2023 по октябрь 2024 года.
- Стоимость привлечения посетителя (CPC) сократилась на 51% при неизменном бюджете.
- 93,77% поискового трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в нише санации и бестраншейного восстановления трубопроводов.
- Заняты позиции в ТОП-10 Яндекса и Google по ключевым коммерческим запросам тематики.

# Кейс продвижения сайта по грузоперевозкам Сигма Транс, пример поискового продвижения сайта в конкурентной тематике

Компания «Сигма Транс» — транспортная компания, которая осуществляет грузоперевозки по России и по Москве, срочные перевозки, экспедиторские услуги и страхование грузов. Профессиональная деятельность компании базируется на безупречном сервисе, который позволяет обеспечить качественную и стабильную работу.

Перейти на сайт: www.sigma-trans.ru

Продвижение сайтов
Грузоперевозки
Корпоративный сайт

Начало сотрудничества:

ноябрь 2012 года

Основные работы:

поисковое продвижение сайтов, проведение маркетингового аудита.

За время сотрудничества семантическое ядро проекта неоднократно увеличивалось, существенно выросла видимость по проекту (до 60%), проект занимает лидирующие позиции по высокочастотным запросам в тематике: [перевозка грузов], [перевозки по Москве] и другие.

Распределение трафика по основным каналам

Максимальная доля посетителей приходит на сайт из поисковых систем, на октябрь 2016 года данный сегмент составлял 87% (порядка 4 тысяч переходов) от общего трафика. 8% пользователей переходит на сайт посредством прямых заходов и около 4% трафика приходится на внутренние переходы.

# Поисковое продвижение сайта компании «BlessLight»

Blesslight — компания, специализирующаяся на продаже светотехнической продукции, включая интерьерное и архитектурное освещение, светильники и комплектующие для жилых и коммерческих помещений.

Описание работ

1. **Построили структуру интернет-магазина дизайнерского освещения**
 - Спроектировали конверсионную структуру коммерческих страниц — создали детальные страницы для каждой коллекции дизайнеров и брендов. Разработали уникальные страницы товаров с полными характеристиками, добавили в превью информацию о статусе товара и его популярности.
 - Создали систему фильтрации товаров с выводом всех заполненных характеристик на листингах. Добавили индикаторы рейтинга и популярности товаров — теперь посетители сразу видят, какие позиции пользуются наибольшим спросом.
2. **Написали уникальный контент для дизайнеров и брендов**
 - Погрузились в тематику дизайнерского освещения и создали серию экспертных материалов: о коллекциях известных брендов Flos, Artemide, Bocci, о дизайнерах Поуле Хеннингсене и Филиппе Старке, об особенностях винтажного и современного освещения.
 - Создали страницы коллекций на страницах дизайнеров, подготовили и разместили информационные статьи. Написали описания для карточек товаров с низкой конверсией, добавили экспертные отзывы.
3. **Доработали сайт под реальные потребности покупателей**
 - Добавили функционал «Купить в 1 клик» для упрощения процесса заказа. Разместили информацию о гарантиях на страницах товаров. Внедрили функционал вывода рейтинга товаров.
 - Создали стикеры видеообзоров для листингов и карточек товаров. Доработали шаблоны карточек товаров под вывод видеоконтента. Корректировали адаптивную версию сайта для улучшения пользовательского опыта.
4. **Решили нестандартные задачи**
 - Внедрили систему генерации описаний к товарам с помощью AI. Настроили электронную коммерцию для отслеживания конверсий. Пересобрали главное меню сайта для улучшения навигации.
 - Добавили вхождения дизайнеров в H1 товаров для повышения релевантности. Корректировали названия разделов. Заполнили теги ALT и TITLE для изображений на уровне шаблона.
 - Внедрили для раздела статей canonical, микроразметку Article, картинки анонсов. Проанализировали и устранили причины проседания видимости.

Результат комплексного подхода

Комплексное выполнение данных задач позволило:

- Увеличить количество запросов в топ-10 поисковой выдачи — достигли существенного роста небрендовых запросов в первую десятку результатов поиска.
- Увеличить органический трафик без брендовых запросов на 218% за период с августа 2024 по ноябрь 2025 года.
- Расширить семантическое покрытие — охватили весь спектр запросов в сфере дизайнерского освещения, винтажных светильников и дизайнерской мебели.

Такой комплексный подход к SEO-оптимизации создал прочную основу для роста поискового трафика в нише дизайнерского освещения и мебели.

## Анализ прироста поискового трафика

За 16 месяцев (август 2024 — ноябрь 2025) поисковый трафик без брендовых запросов вырос в 3,2 раза — это прирост на 218%.

Итог

- 55,34% трафика приходится на общие тематические запросы, что подтверждает эффективность работы с целевой аудиторией в нише дизайнерского освещения.
- Заняты лидирующие позиции в Яндексе и Google по ключевым запросам дизайнерского освещения, винтажных светильников и дизайнерской мебели.

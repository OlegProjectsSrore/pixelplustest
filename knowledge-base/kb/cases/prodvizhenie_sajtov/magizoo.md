# Привлечение поискового трафика для интернет-магазина Magizoo, раскрутка сайта в тематике товары для животных в Москве

Интернет-магазин MAGIZOO.RU предлагает широкий ассортимент зоотоваров и аксессуаров для животных. На сайте компании всегда можно найти свежие корма, витаминные добавки, домики, игрушки, шампуни и многое другое и все это в одном месте. Никаких изматывающих поездок по городу в поисках нужного товара.

За время своего существования (с 1999 года) компания значительно расширила ассортимент магазина. Сайт с удобным каталогом занимает лидирующие позиции на столичном рынке. На текущий момент Magizoo успешно конкурирует с крупнейшими российскими зоомагазинами, предлагая клиентам выгодные расценки и быструю доставку по Москве и в другие города РФ.

Цель:

увеличение целевого трафика из поисковых систем

Цель проекта — увеличить органический трафик на сайт.

За время сотрудничества по проекту специалистами компании «Пиксель Плюс» проведен комплекс работ, который позволил существенно увеличить входящий целевой трафик:

- анализ и последующая доработка функционала «умного» фильтра;
- массовое создание и оптимизация посадочных под новые запросы;
- создание и оптимизация поддоменов с целью привлечения регионального трафика;
- в рамках разовых услуг было собрано расширенное семантическое ядро на основе сайта-конкурента (лидера рынка) и составлены рекомендации по оптимальной структуре для ее продвижения;
- маркетинговый аудит, который позволил выявить основные ошибки и улучшить коммерческие факторов ранжирования и показатели конверсии сайта.

На текущий момент можно отметить планомерный прирост качественного, целевого трафика из поиска, а также улучшение позиций по продвигаемым ключевым запросам. Работы по проекту продолжаются и специалисты «Пиксель Плюс» видят большой потенциал по его развитию.

## Прирост трафика с начала работ по поисковой оптимизации

Трафик из поисковых систем за период с марта 2018 года по февраль 2019 года вырос на 75% без брендовых запросов и с учетом сезонности.

Распределение трафика по основным каналам*

Основной трафик на сайт приходит за счет переходов из рекламы и поисковых систем. Доля с поиска составляет 37,86%, а именно почти 34 тысячи переходов в месяц.

Итог

Меньше чем за год, по проекту удалось достичь главную цель — увеличить трафик из поисковых систем почти в два раза. В абсолютном значении прирост трафика составил более 14 тысяч целевых переходов без брендовых запросов.

Magizoo.ru вошел в ТОП-10 сайтов по тематике «товары для животных», а также занимает позиции на первой странице поисковой выдачи по популярным и конкурентам запросам.

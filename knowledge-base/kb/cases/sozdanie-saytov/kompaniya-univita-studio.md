# Изготовление сайта под ключ для компании «Univita Studio»

 Создание сайтов

## О заказчике

Компаний «Univita Studio» — одна из крупнейших торгово-производственных компаний, успешно работающая на российском рынке с 1998 года. Сфера деятельности компании – производство и реализация качественных строительных смесей для всех этапов строительства.

Компания «Пиксель Плюс» разработала сайт c каталогом для компании «Univita Studio»

## Особенности проекта

Работает на 1С-Битрикс

Уникальный визуализатор интерьера с возможностью подбора интерьерной краски

Уникальный дизайн

## Дизайн сайта

В рамках работ по разработке сайт c каталогом было разработано
7 уникальных макетов дизайна и написаны более 48 страниц технического задания.

| | Главная страница Главная страница с презентацией и картой дистрибьюторов. |
| | Каталог Каталог с информацией о продукте, а также возможностью расчета количества краски и покупки. |
| | Страница подбор цвета Многоуровневая форма с калькуляцией объема необходимой продукции. |
| | Страница Конфигуратора Страница конфигуратора где в 3 клика можно визуализировать на 3D рендере как будет выглядеть комната с палитрой Univita Studio. |

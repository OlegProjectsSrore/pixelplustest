# Изготовление сайта под ключ для компании «SWG»

«SWG» — светодиодное освещение

 Создание сайтов
 Интернет-магазин

## О заказчике

Компаний «SWG» — существует на рынке с 2011 года. На данный момент в компании насчитывается 27 магазинов в 10 городах России и СНГ, а так же 4 филиала со складами.

Компания «Пиксель Плюс» разработала интернет-магазин для компании «SWG»

## Особенности проекта

Работает на 1С-Битрикс

Интеграция с 1С

Уникальный дизайн

Каталог продуктов с фильтрацией

Функция быстрого просмотра

Номинант конкурса
«Рейтинг Рунета» 2019
(Интернет-магазины)

## Дизайн сайта

В рамках работ по разработке интернет-магазина было разработано
12 уникальных макетов дизайна и написаны более 100 страниц технического задания.

| | Главная страница Главная страница сайта с полным каталогом товарной продукции. |
| | О компании Страница о компании с инфографикой в виде маршрута по истории компании. |
| | Каталог товаров Каталог товаров с фильтром и сортировкой, а также с возможностью товар добавить в корзину и пердпросмотром товарной позиции без перехода на карточку товара. |
| | Карточка товара Карточка товара с фотографией, описанием и техническими характеристиками товара, а так же с селектором конфигурации товара и возможностью покупки в 1 клик. |

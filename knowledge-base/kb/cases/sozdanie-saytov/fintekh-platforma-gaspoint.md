# Изготовление сайта под ключ для компании «GasPoint»

«GasPoint» — это цифровая финтех-платформа газомоторного топлива

 Создание сайтов
 Online-сервис

## О заказчике

Компания «GasPoint», придумала цифровую финтех-платформу, которая позволяет создать экосистему газомоторного топлива, в которой клиенты смогут удобно и экономично получить услуги по переходу на метан в качестве топлива для транспортных средств.

Компания «Пиксель Плюс» разработала функциональный ландинг для компании «GasPoint»

## Особенности проекта

Работает на WordPress

Личный кабинет

Индивидуальный дизайн

Реализован внутренний калькулятор

Интеграция с ЮКасса

## Дизайн сайта

В рамках работ по разработке лендига для компании «GasPoint» были отрисован уникальный дизайн сатйа.

| | Главная страница Посадочная страница лендинга с калькулятором и переходом в личный кабинет. |
| | Главная страница личного кабинета Страница личного кабинета с формой для оплата задолжности и интеграцией с ЮКасса. |

# Изготовление сайта под ключ для компании «Veiro Professional»

«Veiro Professional» — производитель санитарно-гигиенической продукции для профессионального и домашнего назначения

 Создание сайтов
 Интернет-магазин

## О заказчике

«Veiro Professional» бренд основан в 2005 году на данный момент это одна из самых востребованных компаний в сфере производства санитарно-гигиенической продукции для профессионального и домашнего назначения.

Для сайта крупного производителя бумаги-основы был разработан личный кабинет, в котором осуществлён контроль отгрузки, документооборот между продавцом и покупателем, сохранение шаблонов а для удобной работы с каталогом были созданы: механизм подбора товаров, умный фильтр и функция сравнения торговых предложений

## Особенности проекта

Работает на 1С-Битрикс

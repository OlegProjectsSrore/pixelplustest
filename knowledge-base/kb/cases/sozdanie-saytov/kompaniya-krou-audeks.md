# Изготовление сайта под ключ для компании «Кроу Аудэкс»

«Кроу Аудэкс» — аудит, консалтинг, бухгалтерский учет

 Создание сайтов
 Корпоративный сайт

## О заказчике

Компания «Кроу Аудэкс» основана в 1994 году, на сегодняшний день — это одна из крупнейших аудиторско-консалтинговых компаний России.

Компания «Пиксель Плюс» разработала корпаративный сайт для компании «Кроу Аудэкс»

## Особенности проекта

Работает на 1С-Битрикс

Анкета расчета стоимости аудита

Каталог услуг

7 специалистов были задействованы для работ над проектом

Версия на английском языке

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано

14 уникальных макетов дизайна и написаны более 85 страниц технического задания.

| | Главная страница Страница с каталогом услуг расчетом стоимости и актуальными новостями. |
| | О компании Страница с описанием, фотографиями и сертификатами. |
| | Каталог Каталог услуг с формой обратной связи. |
| | Анкета Анкета расчета стоимости услуг аудита. |
| | Контакты Страница контактов с номерами и адресами всех подразделений компании. |

# Изготовление сайта под ключ для компании «Магизу»

«Магизу» — товары для животных

 Создание сайтов
 Интернет-магазин

## О заказчике

Magizoo — один из лидеров интернет-рынка товаров для животных.

Компания «Пиксель Плюс» разработала интернет-магазин c каталогом для компании «Магизу»

## Особенности проекта

Работает на 1С-Битрикс

Высокая нагрузка
 до 500К пользователей

Около 20-30 интеграций
 с маркетинговыми площадками

## Дизайн сайта

В рамках работ по разработке интернет-магазина было разработано
125 уникальных макетов дизайна и написаны более 130 страниц технического задания.

| | Главная страница Главная страница с каталогом товаров, блоком хит продаж, товар недели, видео обзорами и досками объявлений. |
| | Каталог Открытый каталог продукции, с отображением количества товарных позиций для каждой категории и собственный рейтинг товаров. |
| | Карточка продукта Товарная карточка с возможностью покупки в 1 клик и полной развернутой информацией о товаре включая отзывы. |
| | Каталог статей Каталог статей с меню и фильтром. |

# Изготовление сайта под ключ для компании «Мастер по Маргарите»

«Мастер по Маргарите» — первая пиццерия в Зеленограде с настоящей итальянской дровяной печью

 Создание сайтов
 Online-сервис

## О заказчике

«Мастер по Маргарите» — первая пиццерия в Зеленограде с настоящей итальянской дровяной печью. Пицца уникальна не только способом выпекания на открытом огне, но и неповторимым вкусом.

Компания «Пиксель Плюс» разработала интернет-магазин с меню ресторана.

## Особенности проекта

Работает на 1С-Битрикс

Интеграция с iiko (меню ресторана и заказы)

Возможность добавления в позиции меню доп.ингридиентов

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано

5 уникальных макетов дизайна и написаны более 10 страниц технического задания.

| | Главная страница Страница с полным ассортиментом товарной продукции. |
| | Карточка товара В карточке товара мы интегрировали функционал добавления топингов, для пиццы. |
| | Раздел Доставки Раздел доставки с разграничением зон доставки. |
| | Корзина Корзина с функционалом доставки и возможностью самовывоза. |

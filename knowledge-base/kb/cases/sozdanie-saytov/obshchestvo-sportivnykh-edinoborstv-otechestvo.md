# Изготовление сайта под ключ для компании «Отечество»

Создание сайтов
 Корпоративный сайт

Компанией «Пиксель Плюс» создан сайт для общества спортивных единоборств «Отечество». Организация оказывает всестороннюю помощь молодым талантливым спортсменам в их подготовке к участию в соревнованиях. При Обществе созданы юношеские команды по борьбе самбо и дзюдо, в которые привлекаются перспективные спортсмены.

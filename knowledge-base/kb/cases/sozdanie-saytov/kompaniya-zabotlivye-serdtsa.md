# Изготовление сайта под ключ для компании «Заботливые сердца»

«Заботливые сердца» — сеть частных пансионатов для пожилых людей в Москве и Подмосковье

 Создание сайтов
 Сайт-визитка

## О заказчике

Сервис «Заботливые сердца» — актуализированная база для поиска и сравнения профильных учреждений для реабилитации, постоянного или временного проживания, отдыха престарелых людей в Москве и области.

Компания «Пиксель Плюс» разработала агрегатор пансионатов «Заботливые сердца»

## Особенности проекта

Работает на 1С-Битрикс

Индивидуальные карточки пансионатов с полной информацией об объекте

Поиск пансионатов по карте

# Изготовление сайта под ключ для компании «ИВБЭБИ»

«ИВБЭБИ» — магазин детской и женской одежды российского производителя

 Создание сайтов
 Интернет-магазин

## О заказчике

Фабрика «ИВБЭБИ» расположена в городе Иваново Ивановской области. Оптово-розничные точки продаж компании расположены в Иваново и Ярославле.

Компания «Пиксель Плюс» разработала интернет-магазин для компании «ИВБЭБИ»

## Особенности проекта

Работает на 1С-Битрикс

Функция сравнения товарных позиций

Каталог товаров

## Дизайн сайта

В рамках работ по разработке интернет-магазина было разработано

7 уникальных макетов дизайна и написаны более 40 страниц технического задания.

| | Главная страница Страница с каталогом товаров и разделом лучшие предложения. |
| | Каталог Каталог с фильтром и рейтингом товара. |
| | Карточка товара Карточка товара с фильтрами по размерам, системой сравнения товара и блоком с схожими товарами. |
| | Каталог Страница корзины фильтром по позициям и возможностью оформления заказа в 1 клик. |

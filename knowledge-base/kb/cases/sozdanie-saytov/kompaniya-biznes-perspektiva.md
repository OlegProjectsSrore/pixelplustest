# Изготовление сайта под ключ для компании «Бизнес перспектива»

Бизнес перспектива — бухгалтерские услуги

 Создание сайтов
 Корпоративный сайт

## О заказчике

«Бизнес перспектива» предлагает ведение бухгалтерского учета и налогообложения в Москве и других городах России.

Компания «Пиксель Плюс» разработала корпоративный многостраничный сайт для компании «Бизнес Перспектива»

## Особенности проекта

Работает на 1С-Битрикс

Реализован внутренний калькулятор

A/B-сплит тестирование страниц для отслеживания лучшего показателя конверсии

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано

15 уникальных макетов дизайна и написаны более 65 страниц технического задания.

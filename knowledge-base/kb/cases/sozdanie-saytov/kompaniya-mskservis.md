# Изготовление сайта под ключ для компании «МСКСЕРВИС»

«МСКСЕРВИС» — услуги клининга и химчистки в Москве

 Создание сайтов
 Корпоративный сайт

## О заказчике

«МСКСЕРВИС» — компания, которая уже на протяжении многих лет оказывает качественные услуги клининга на территории Москвы.

Компания «Пиксель Плюс» разработала сайт c каталогом и калькулятором услуг для компании «МСКСЕРВИС»

## Особенности проекта

Работает на 1С-Битрикс

Реализован внутренний калькулятор

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано более

20 уникальных макетов дизайна и написаны более 30 страниц технического задания.

| | Главная страница Главная страница на которой рассказана главная информация о компании — какие услуги оказывает с какой техникой и химией работает, а так же какие гарантии предоставляет. |
| | Каталог Раздел услуг с полным прайсом по каждому виду работ. |
| | Страница услуги Внутренняя страница услуги с калькулятором. |
| | Калькулятор Отдельный калькулятор под тип помещения. |

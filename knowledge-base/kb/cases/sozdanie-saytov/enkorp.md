# Изготовление сайта под ключ для компании «ЭНКОРП»

ЭНКОРП — аутстаффинг персонала для производства железнодорожных локомотивов и подвижного состава

 Создание сайтов
 Корпоративный сайт

## О заказчике

Компания «Энкорп» эксперт аутстаффинга и аутсорсинга в машиностроительной отрасли.

Компания «Пиксель Плюс» разработала сайт c личным кабинетом для заказчика и специалиста компании «ЭНКОРП»

## Особенности проекта

Работает на 1С-Битрикс

Личный кабинет заказчика и соискателя

Мультирегиональность

Калькулятор расчета стоимости найма сотрудника по отраслям

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано
20 уникальных макетов дизайна и написаны более 156 страниц технического задания.

| | Дизайн сайта Главная страница с переходом в личный кабинет специалиста и заказчика. |
| | Услуги Страница услуг ведет нас по основным услугам компании, так же на странице предусмотрена большая форма для заполнения заказчиком. |
| | Карьера На этой странице специалист может заполнить анкету для трудоустройства и посмотреть актуальные вакансии. |
| | Личный кабинет заказчика В личном кабинете заказчик может сформировать заказ на подбор сотрудников для его задачи, отслеживать текущие заказы, самостоятельно подбирать персонал и наблюдать за историей своих заказов. |
| | Личный кабинет заказчика В личном кабинете заказчик может при помощи фильтра отбирать подходящих кандидатов на работу самостоятельно. |

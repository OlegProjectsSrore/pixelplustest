# Изготовление сайта под ключ для компании «Стройтраст»

ООО «Стройтраст» — заказчик-застройщик, специализирующийся на строительстве современного комфортного жилья в Твери и Тверской области.

 Создание сайтов
 Корпоративный сайт

Компания «Пиксель Плюс» разработала корпоративный сайт для компании «СТРОЙТРАСТ».

При разработке мы создали уникальные страницы для каждого строящегося объекта. Так же был разработан рендер внешнего вида дома и прилежащей территории, поэтажные планы и рендер квартир.

Мы создали удобную «шахматку» для наглядного просмотра расположения квартиры, а так же автоматизировали процесс наполнения сайта квартирами и последующее распределение контента.

## Особенности проекта

Автоматизация наполнения квартир

8 специалистов были задействованы для работ над проектом

A/B-сплит тестирование страниц для отслеживания лучшего показателя конверсии

Отрисованы 3D модели домов и квартир

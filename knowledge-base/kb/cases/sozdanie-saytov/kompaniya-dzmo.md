# Изготовление сайта под ключ для компании «ДЗМО»

«ДЗМО» — производство медицинской мебели

 Создание сайтов
 Интернет-магазин

## О заказчике

Компания «ДЗМО» — российский производитель медицинской мебели работает с 1936 года и совершает более 3000 отгрузок в год.

Компанией «Пиксель Плюс» разработала интернет-магазин для компании «ДЗМО»

## Особенности проекта

Работает на 1С-Битрикс

Каталог продукции с фильтром категорий

Калькулятор доставки

Многорегиональность

## Дизайн сайта

В рамках работ по разработке интернет-магазина было разработано
13 уникальных макетов дизайна и написаны более 67 страниц технического задания.

| | Главная страница Главная страница сайта с каталогом продукции компании разделом «как купить» и отзывами. |
| | Каталог Каталог продукции с боковым фильтром и поисковой строкой. |
| | Карточка товара Карточка товара с возможностью выбора модификации товара, техническими характеристиками, а также с фото и видео материалами. |
| | Страница доставки Страница доставки с подробностями о способах доставки и калькулятором стоимости доставки. |

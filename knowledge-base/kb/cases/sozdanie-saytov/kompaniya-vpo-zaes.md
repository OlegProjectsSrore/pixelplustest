# Изготовление сайта под ключ для компании «ВПО «ЗАЭС»»

Создание сайтов
 Сайт-визитка

Компанией «Пиксель Плюс» создан сайт для компании «ВПО «ЗАЭС» занимающейся технической приемкой ядерного топлива, экспертизой проектно-конструкторской документации и выполняющей аудиты обеспечения качества предприятий.

## Дизайн сайта

| | Главная страница |
| | Страница интерактивной карты России |
| | Страница с элементами фирменного стиля компании |
| | Страница новостей отрасли |
| | Страница с перечнем документов |

Посмотреть сайт в интернете:

zaes.ru

В рамках работ по разработке сайта был проделан целый комплекс работ, включающий в себя: создание дизайна сайта, интеграцию с системой управления «1С-Битрикс» и размещение сайта на сервере. На всех этапах работ коллектив компании «Пиксель Плюс» зарекомендовал себя исключительно с положительной стороны, благодаря слаженной и профессиональной работе специалистов.

# Изготовление сайта под ключ для компании «Ailisa»

Создание сайтов
 Интернет-магазин

Компанией «Пиксель Плюс» создан сайт для компании ООО «Аилиса», которая является представителем Китайской обувной фабрики «Aiminer». На российском рынке фабрика представляет бренд под торговой маркой «Аilisa» и занимается оптовой продажей высококачественной женской кожаной обуви..

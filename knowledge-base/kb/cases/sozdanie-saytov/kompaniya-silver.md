# Изготовление сайта под ключ для компании «Сильвер»

«СИЛЬВЕР» — экосистема, которая включает в себя уже более 14 брендов

 Создание сайтов
 Корпоративный сайт

## О заказчике

«СИЛЬВЕР» — группа официальных автомобильных дилеров брендов LADA, Hyundai, Mitsubishi, BMW, KIA, Chevrolet Niva, УАЗ, а также автомобильный гипермаркет по продаже проверенных автомобилей с пробегом.

Компания «Пиксель Плюс» разработала корпоративный сайт для компании «Сильвер»
с возможностью проверки наличия автомобиля онлайн

## Особенности проекта

Каталог 14 марок автомобилей

8 специалистов были задействованы для работ над проектом

A/B-сплит тестирование страниц для отслеживания лучшего показателя конверсии

## Дизайн сайта

В рамках работ по разработке корпоративного сайта было разработано
35 уникальных макетов дизайна и написаны более 70 страниц технического задания.

| | Главная страница Создание корпоративного сайта с каталогом продукции для компании «Сильвер». |
| | Страница товара Детальная страница товара позволяет подробно ознакомиться с характеристиками товара, качественными и крупными фотографиями модели, а так же сделать заказ понравившейся товарной позиции. |
| | Страница блога На этой странице показаны все актуальные статьи. Они оформлены в виде карточек. |
| | Страница кредитного калькулятора На этой странице пользователь может посчитать с помощью калькулятора сумму кредита, ежемесячный платеж и свою кредитную ставку. |
| | Страница сервисного обслуживания На этой странице представлены сервисные центры компании, оформленные в виде карточек. |

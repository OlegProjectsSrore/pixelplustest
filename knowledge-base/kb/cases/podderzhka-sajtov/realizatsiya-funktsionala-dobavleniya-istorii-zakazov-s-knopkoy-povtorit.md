# Кейс «Реализация функционала добавления истории заказов с кнопкой повторить» от отдела поддержки компании Пиксель Плюс для сайта lavashura.ru

Поддержка сайтов
Сайт-визитка

## Проблема

У пользователей сайта не было возможности повторить из личного кабинета свой ранее оформленный заказ.

## Решение

Компанией «Пиксель Плюс» реализован функционал добавления истории заказов с кнопкой Повторить. После нажатия на нее в корзину падают товары, которые ранее были в заказе.

## Реализация

- Добавили в заказах кнопку Повторить:
- При нажатии сразу происходит очистка текущей корзины, так как в ней могли быть ранее добавленные товары. После очистки корзины добавляются товары из выбранного заказа и происходит переадресация на страницу корзины.

После проверки работ на тестовой площадке настроили функционал повторения заказа на боевом сайте.

## Итоги работы

В личном кабинете реализован функционал добавления истории заказов с кнопкой Повторить. После нажатия на нее в корзину падают товары, которые были в заказе.

# Кейс «Реализация функционала запуска обедов по расписанию с помощью скрипта» от отдела поддержки компании Пиксель Плюс для сайта lavashura.ru

Поддержка сайтов
Сайт-визитка

## Проблема

Отсутствовал функционал запуска обедов по расписанию с 12:00 до 18:00.
Все остальное время эти позиции должны быть недоступны для заказа в iiko. Эту информацию нужно передавать на сайт по интеграции.

## Решение

Компанией «Пиксель Плюс» реализован функционал запуска обедов по расписанию с 12:00 до 18:00 с помощью скрипта.

## Реализация

- Реализован скрипт, который отключает заказ обедов по расписанию. Пользователи сайта могут заказать обеды с 12:00 до 18:00 часов. Все остальное время эти позиции недоступны для заказа в iiko.
- Когда скрипт запускает расписание, кнопка «В корзину» становится неактивной и обед нельзя заказать.

## Итоги работы

Реализован функционал запуска обедов по расписанию с 12:00 до 18:00 с помощью скрипта.

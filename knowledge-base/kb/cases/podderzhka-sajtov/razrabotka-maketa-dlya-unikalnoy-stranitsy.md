# Кейс «Разработка макета для уникальной страницы» от отдела поддержки компании Пиксель Плюс для сайта instocktech.ru

Поддержка сайтов
Корпоративный сайт

InStock Technologies — российская IT-компания, специализирующаяся на автоматизации складской логистики и внедрении WMS-систем для бизнеса. Компания разрабатывает собственное ПО InStock WMS и помогает клиентам управлять складами, маркировкой и логистическими процессами.

## Проблема

Было необходимо разработать уникальный макет страницы по внедрению WMS-систем для складов продуктовой отрасли. Важно было сохранить единый стиль сайта, учесть уже используемые UI-элементы и выстроить понятную структуру страницы с современным визуальным оформлением.

## Решение

Был разработан и согласован с клиентом макет страницы для трех разрешений экранов с использованием UI-кита.

## Реализация

В рамках задачи был разработан и согласован уникальный макет страницы по внедрению WMS-систем для складов продуктовой отрасли. Основной целью было повышение конверсии сайта за счет более понятной структуры и адаптивного интерфейса, поэтому дизайн был сразу продуман для мобильной, планшетной и десктопной версий.

После внутреннего согласования макет был доработан: из информационного блока с таблицей убрали графу с ценами по согласованию с заказчиком, а саму структуру переработали с акцентом на сроки внедрения. Обновлённая версия была финализирована и подготовлена к дальнейшей разработке.

Работа велась в Figma с использованием UI-кита, что позволило сохранить единый визуальный стиль и ускорить процесс разработки.

## Итоги работы

Работа завершена успешно: клиент получил полноценный готовый к реализации макет страницы, который учитывает требования к адаптивности, единый визуальный стиль и удобство дальнейшей разработки.

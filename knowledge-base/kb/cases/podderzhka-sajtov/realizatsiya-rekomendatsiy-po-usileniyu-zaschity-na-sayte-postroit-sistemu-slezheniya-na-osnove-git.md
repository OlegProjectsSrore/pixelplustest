# Кейс «Усиление защиты сайтов через GIT» от отдела поддержки компании Пиксель Плюс для сайта pack-store.ru

Поддержка сайтов
Интернет-магазин

Компания PACK-STORE занимается оптовой и розничной продажей упаковочных материалов и оборудования: коробок, пакетов, плёнок, скотча, упаковки для маркетплейсов и расходных материалов для бизнеса.

## Проблема

Требовалось усилить защиту сайтов клиента от возможных атак. Необходимо было разработать систему слежения за изменениями файлов с использованием GIT, чтобы иметь возможность оперативно выявлять и реагировать на любые изменения. Это особенно важно в условиях постоянных угроз безопасности.

## Решение

Выполнили настройку системы слежения на основе GIT, которая охватывает все сайты клиента. Сохранили возможность автоматического коммита изменений в репозиторий и настроили уведомления о подозрительных изменениях. Проверили работоспособность системы и ее интеграцию с текущими процессами.

## Реализация

## Задача

Необходимо было построить систему слежения за изменениями файлов на сайтах клиента с использованием GIT. Цель заключалась в повышении уровня безопасности и возможности оперативного реагирования на угрозы, путем отслеживания изменений в коде и настройке уведомлений о подозрительных действиях.

## Что было сделано

- Настроили систему слежения на основе GIT для всех сайтов клиента.
- Обеспечили автоматический коммит правок в репозиторий.
- Настроили уведомления о изменениях в файлах.
- Проверили корректность работы системы слежения.
- Создали интерфейс для запуска скрипта слежения.
- Реализовали поддержку inotify для моментального отслеживания изменений.
- Мониторим работу системы в течение нескольких дней.

## Результат

Система слежения за изменениями файлов была успешно внедрена и функционирует корректно. Все изменения фиксируются, и при наличии подозрительных строк кода отправляются уведомления в Telegram для оперативного реагирования.

Сейчас система находится в процессе мониторинга, что позволит оценить ее эффективность и внести возможные улучшения в будущем.

## Особенности

При подходе к работе над проектом было важно обеспечить надежный механизм отслеживания изменений, что позволяет минимизировать риски. Внедрение GIT на более глубоком уровне позволяет контролировать все файлы, включая те, которые традиционно исключаются из отслеживания.

В процессе работы были выявлены ограничения на уровне хостинга, касающиеся количества файлов, которые можно отслеживать с помощью inotify. Это важно учитывать при дальнейшем развитии системы.

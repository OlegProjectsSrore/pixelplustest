# Кейс «Доработка блока характеристик и фильтрации для сайта winegadgets.ru» от отдела поддержки компании Пиксель Плюс для сайта winegadgets.ru

Поддержка сайтов
Интернет-магазин

Интернет-магазин аксессуаров для вина WineGadgets поможет вам приобрести все, что необходимо для получения еще большего удовольствия от величайшего напитка человечества - вина.

В производство вина винодел вкладывает душу и очень-очень много труда. Чтобы труд винодела не пропал даром, необходимы правильно подавать и употреблять вино, правильно его хранить. В этом вам помогут товары, представленные в нашем магазине - бокалы, декантеры, штопоры, стеллажи и другие аксессуары для вина.

## Проблема

В карточках товаров отображалось небольшое количество характеристик, и пользователям не хватало информации для выбора вина. Также покупатели не могли посмотреть весь ассортимент каталога по выбранному параметру.

## Решение

Специалисты «Пиксель Плюс» предложили такие решения:

1. Вывести в блоке все характеристики из фильтра каталога.
2. Сделать свойство в блоке характеристик кликабельным. Ссылка должна вести на страницу, где отображаются все товары с таким же свойством.

## Реализация

1. Реализовали вывод дополнительных характеристик.

2. Добавили гиперссылки с переходом на ознакомительную страницу.

3. Реализовали запрет на вывод свойства - если свойство не заполнено, оно выводиться не будет.

4. Добавили в фильтр дополнительные свойства из предоставленного нам клиентом файла.

## Итоги работы

Расширенный блок характеристик в карточке товара с возможностью перехода в фильтр по клику на любое свойство. Удобный подбор ассортимента по параметрам.

# Кейс «Настройка отображения чек-бокса в корзине для новых клиентов» от отдела поддержки компании Пиксель Плюс для сайта www.stmwater.ru

Свою деятельность компания «Источник Старо-Мытищинский» начала в далеком 1993 году с производства лимонадов, в основе которых была все та же знаменитая Мытищинская вода. Но со временем, вероятно, ввиду того, что люди стали больше задумываться о своём здоровье, вырос спрос на чистую питьевую воду.

## Проблема

Чекбокс «Заказ и адрес подтверждаю, звонок оператора не требуется» отображался для пользователей, которые еще не были заведены в 1С.
Его было необходимо скрывать и показывать только после совершения первого заказа, так как клиент новый и по умолчанию с ним необходимо предварительно созваниваться и заводить данные о нем в 1С.

## Решение

Компанией «Пиксель Плюс» перенастроено отображение чекбокса в корзине для нового пользователя. Этот чекбокс будет появляться после первого заказа.

## Реализация

На сайте в корзине настроено скрытие чекбокса для нового пользователя.
Чекбокс становится доступен только после совершения первого заказа.

## Итоги работы

Реализована доработка по отображению чекбокса в корзине для новых клиентов. Теперь этот чекбокс будет появляться только после первого заказа. Теперь менеджеры всегда будут своевременно связываться с новыми клиентами и заводить необходимые данные в 1С.

## Компания Атол в цифрах

## Проблема

У клиента отсутствовала платформа с удобным функционалом для сбора заявок. Она была необходима для проведения акции.

## Решение

Компания «Пиксель Плюс» в качестве платформы предложила использовать сайт. На базе дизайна существующей формы обратной связи на сайте была разработана анкета в соответствии с вводными от заказчика.

## Реализация

При вводе ИНН в поле «ИНН партнера» автоматически подтягиваются данные в поля «Название компании» и «ФИО менеджера».

Автозаполнение после ввода:

Поле «Город» (выпадающий список) заполняется с указанием региона, есть выбор из списка.
Список городов подтягивается из API подсказок по ФИАС - DaData.

В зависимости от количества, указанного в поле «Данные о ТСД (сдаваемых в Трейд-ин)» ниже в форме автоматически появляется/сокращается число блоков до нужного количества:

Для поля «Город» (выпадающий список) настроено подтягивание списка городов из API подсказок по ФИАС - DaData.

Анкеты, заполненные на сайте, попадают в административную панель сайта.

Было настроено API для прямой передачи анкет в режиме онлайн в таблицу Google Docs.

## Итоги работы

Настроен и отлажен процесс отправки данных в Google Docs таблицу клиента. Доработана форма обратной связи для более успешного взаимодействия пользователя с ней.
С помощью вышеописанных работ ускорились процессы обработки заявок с сайта.

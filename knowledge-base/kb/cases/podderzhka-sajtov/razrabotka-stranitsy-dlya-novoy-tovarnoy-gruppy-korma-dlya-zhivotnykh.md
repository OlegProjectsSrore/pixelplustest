# Кейс «Разработка страницы для товарной группы «Корма для животных»» от отдела поддержки компании Пиксель Плюс для сайта trekmark.ru

«Трекмарк» - разработчик, производитель и интегратор комплексных решений для цифровой маркировки.

## Проблема

Компания начала работать с новой товарной группой «Корма для животных», однако информация об этом отсутствовала на сайте.

## Решение

Компанией «Пиксель Плюс» разработана и интегрирована на сайт страница для новой товарной группы «Корма для животных».

## Реализация

1. Проанализировали структуру страниц на сайте
2. Создали макет страницы
3. Сверстали и интегрировали

## Итоги работы

Разработана и интегрирована на сайт страница для новой товарной группы «Корма для животных». Теперь посетители сайта видят, что компания работает с данной товарной группой.

# Кейс «Реализация новой акции на сайте» от отдела поддержки компании Пиксель Плюс для сайта truewater.ru

Поддержка сайтов
Сайт-визитка

«Настоящая вода» добывается в уникальном по чистоте месте - Касимовском водоносном горизонте — с глубины более 100 м. Компания принимает все меры для сохранения ее качества, чтобы кулеры в офисах были наполнены действительно полезным и экологически чистым продуктом.

## Проблема

На сайте отсутствовала механика «2 товара по цене 1».

## Решение

Настроили работу акции, согласно которой при добавлении в корзину товара, автоматически добавляется такой же со стоимостью 0 руб. Добавили текст условия акции и карточку для добавления в корзину.

## Реализация

Реализовали механику для акций: «2 газированных воды СТМ 1,5л по цене 1» и «2 упаковки по цене 1».
В акции отображается товар - вода СТМ 1.5 литра газ. При добавлении данной позиции в корзину, добавляется вторая такая же вода за 0 руб.
Для информирования покупателей сделали баннер и разместили текст акции с карточкой для добавления в корзину.

## Итоги работы

Реализовали механику для акций: «2 газированных воды СТМ 1,5л по цене 1» и «2 упаковки по цене 1». При добавлении данных позиций в корзину второй аналогичный товар автоматически добавляется со стоимостью 0 руб. Заходя на сайт, покупатели видят баннер, условия акции и сразу же могут добавить акционный товар в корзину.

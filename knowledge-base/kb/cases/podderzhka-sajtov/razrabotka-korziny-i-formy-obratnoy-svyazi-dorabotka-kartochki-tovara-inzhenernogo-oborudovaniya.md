## Проблема

У компании большое количество офисов по всей стране. Необходимо отобразить контактную информацию всех офисов, чтобы ее было легко найти пользователям сайта.

## Решение

Компанией «Пиксель Плюс» в качестве решения предложена доработка страницы «Контакты» с отображением всех офисов на карте и удобной фильтрацией для поиска.

## Реализация

1. Отрисован дизайн-макет нового вида страницы «Контакты».

В макете были отражены следующие элементы:

- вкладка с классификацией офисов
- карта с отмеченными офисами
- над картой размещены теги с названиями городов
- адреса на карте отмечены указателем с логотипом АДЛ
- окно с информацией о данном офисе: адрес, телефон, часы работы и кнопка «Перейти»
- блок с информацией об офисах в виде прокручивающегося списка слева от карты

На этапе интеграции дизайн-макетов учтены следующие требования:

- в разделе Контакты добавлена новая вкладка «Все офисы АДЛ».
 Новая вкладка «Все офисы АДЛ» открывается по умолчанию первом при переходе на страницу «Контакты» https://adl.ru/contacts/.
- карта при переходе на страницу должны отображаться в таком масштабе, чтобы были видны все отмеченные офисы. При этом на карте должны быть доступны инструменты Яндекс.Карт, которые позволяют изменять масштаб карты.
- при нажатии на объект должно появляться окно с информацией о данном офисе: адрес, телефон, часы работы и кнопка «Перейти». При нажатии на кнопку «Перейти» (в текущей вкладке браузера) должна открываться страница с информацией о данном офисе.
 Пример страницы: https://adl.ru/contacts/predstavitelstva-i-distribyutory/moskva/
- в блоке со списком городов должна отображаться следующая информация об объектах: адрес, телефон, часы работы и кнопка «Перейти».
 Адреса офисов должны отображаться в порядке, который выбран заказчиком.
 Карта и блок с информацией должны быть в виде единого окна.
- над картой должны быть размещены теги с названиями городов. Список тегов, которые необходимо разместить был предоставлен заказчиком. При клике на тег должен отображаться выбранный город с активным окном информации:
- изменены *title* и *description* для страницы на следующие:
 *Title*: Все офисы АДЛ – адреса, телефоны, режим работы
 *Description*: Карта с адресами офисов компании АДЛ

## Итоги работы

Реализованная страница «Контакты» с объектами на карте. На карте отображаются все офисы России с указанием их адресов. Карта масштабируется. Легко найти нужные контакты офиса.

# Кейс «Верстка сайта agroex.ru, интеграция с сервисом погоды meteoblue.com» от отдела поддержки компании Пиксель Плюс для сайта www.agroex.ru

Поддержка сайтов
Корпоративный сайт
Производство

«Агро Эксперт Груп» — одно из крупнейших российских предприятий по производству и продаже химических средств защиты растений. Компания производит около 8 % всех ХСЗР, используемых аграриями в России.

## «Агро Эксперт Груп» в цифрах:

## Проблема

В 2022 году компания «Агро Эксперт Групп» отметила юбилей — 20 лет на рынке. Но текущий сайт заказчика имел устаревший дизайн и не отвечал современным требованиям. В честь этого события нужно было обновить дизайн сайта и внедрить новый функционал. Заказчик сам предоставил макет дизайна.

## Решение

Специалисты «Пиксель Плюс» сверстали и внедрили макеты заказчика, провели интеграцию по API с сервисом погоды meteoblue.com.

## Реализация

1. Выполнена адаптивная верстка 28 макетов и интегрирована с CMS 1С-Битрикс.
2. В каталоге продуктов и на странице Контакты реализован селект по выбору страны:
3. Проведена интеграция по API с сервисом погоды meteoblue.com https://agroex.ru/servisy/pogoda/

 В сервисе предусмотрен выбор местоположения для корректного определения прогноза погоды. Отображаются данные для опрыскивания сельхоз растений.

## Итоги работы

Выполнен редизайн сайта по макетам, предоставленным заказчиком; сохранена функциональность сайта и возможность редактирования контента в административной панели CMS 1С-Битрикс; произведена интеграция с сервисом погоды meteoblue.com.

# Кейс «Реализация дополнительной опции к товару» от отдела поддержки компании Пиксель Плюс для сайта ecokamin.ru

Поддержка сайтов
Корпоративный сайт
Производство

ЭкоКамин это популярные бренды, это десятки тысяч произведенных высокотехнологичных единиц продукции, это собственный завод, это сотни магазинов партнеров по всей России и странам ближнего зарубежья.

## Проблема

В карточке товара отсутствовал функционал привязки дополнительной опции к товару при добавлении товара в корзину.

## Решение

Реализовать функционал привязки дополнительной опции к товару при добавлении товара в корзину.

## Реализация

Требовалось реализовать функционал привязки дополнительной опции к товару при добавлении товара в корзину:

- Топка без шибера
- Топка с Комплектом шиберной заслонки

Кнопки появляются если к данной позиции привязана шиберная заслонка.
Т.е. должен быть предусмотрен механизм привязки к позиции шиберной заслонки из группы «Шиберные заслонки», причем к позиции можно привязать одну, либо более позиций.

Если к топке не привязана шиберная заслонка, то обе кнопки просто не появляются.

По умолчанию «горит» первая кнопка. Одновременно может гореть только одна из двух кнопок. Соответственно, клиент может их переключать по своему усмотрению.

По умолчанию «горит» первая кнопка. Одновременно может гореть только одна из двух кнопок.
Соответственно, клиент может их переключать по своему усмотрению.

Если горит вторая кнопка то, в карточке товара изменение касаются только цены. К цене
прибавляется стоимость привязанной шиберной заслонки. Т.е. отображается цена товара плюс
цена шиберной заслонки.
При заказе в корзину падает позиции: сам товар + привязанные
позиции из раздела Шиберные заслонки. Со всеми действующими на данные позиции акциями.

Этапы реализации

1. Сделали новый функционал с выводом двух кнопок. Сделали возможность выбора с шибером или нет. Работает со скидкой и без.

2. Для этого создали новое свойство в админке с привязкой к элементам инфоблока.

3. В корзину добавляется товар с дополнительной позицией, если позиция выбрана или нет (со всем скидками).

## Итоги работы

Реализовали новый функционал с выводом двух кнопок. Сделали возможность выбора опций по желанию.
Создали новое свойство в админке с привязкой к элементам инфоблока. По итогу: В корзину добавляется товар с дополнительной позицией, если позиция выбрана (со всем скидками) или нет.

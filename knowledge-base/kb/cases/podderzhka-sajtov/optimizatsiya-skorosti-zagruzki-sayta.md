# Кейс «Оптимизация скорости загрузки сайта» от отдела поддержки компании Пиксель Плюс для сайта magizoo.ru

Поддержка сайтов
Интернет-магазин
Зоотовары

## Проблема

Сайт клиента загружался очень медленно. Это создавало дискомфорт для пользователей, совершавших покупки.

## Решение

Компанией «Пиксель Плюс» был проведен технический аудит сайта и сделаны работы по оптимизации скорость загрузки.

## Реализация

Провели технический аудит по результатам которого были проведены следующие работы:

1. Доработали оптимизацию изображений:

- настроили всем изображениям lazyload («ленивую загрузку»)

- сделали конвертацию в webp (облегченный формат картинок для веб).

2. Переверстали карточку товара так, чтобы убрать сдвиг страницы

3. Уменьшили время обновления контента на сайте

4. Настроили загрузку js скриптов только там, где они используются

5. Подключили min версии js/css

6. Прописали font-display: swap

7. Убрали загрузку js ядра для попапов main.popup.bundle.js

8. Отключили загрузку yandex share

## Итоги работы

По итогам работ сайт стал работать гораздо быстрее, а показатель отказов в Яндекс.Метрике снизился на 20%.

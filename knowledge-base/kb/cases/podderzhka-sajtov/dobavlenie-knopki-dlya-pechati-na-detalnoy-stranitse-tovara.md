# Кейс «Добавление кнопки для печати на детальной странице товара» от отдела поддержки компании Пиксель Плюс для сайта www.uralaz.ru

Поддержка сайтов
Корпоративный сайт

Автомобильный завод «УРАЛ» — один из лидеров российского машиностроения. Расположен в городе Миассе Челябинской области.

## Автомобильный завод «УРАЛ» в цифрах:

Более 4000 сотрудников

Выпущено более 1,4 млн автомобилей

Завод работает с 1941 года

## Проблема

У посетителей сайта автомобильного завода «УРАЛ» не было возможности сформировать файл с основными характеристиками продукции и скачать его.

## Решение

Специалисты компании «Пиксель Плюс» добавили возможность формировать PDF-файл с основными характеристиками автомобиля, габаритным чертежом и возможностью распечатать файл при клике на кнопку «Версия для печати».

## Реализация

В ходе реализации задачи специалисты столкнулись с проблемой игнорирования части стилей в библиотеке генерации PDF. Проблема была решена, а стили приведены к внешнему виду, который требовался клиенту.

Был выведен файл с нумерацией страниц, изображением, габаритным чертежом и основными характеристики автомобиля.

## Итоги работы

На карточке товара появилась функция «Версия для печати», которая помогает пользователям в выборе автомобиля.

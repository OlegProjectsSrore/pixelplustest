# Кейс «Magizoo.ru — кейс интеграция с OZON» от отдела поддержки компании Пиксель Плюс для сайта magizoo.ru

Поддержка сайтов
Зоотовары

Magizoo.ru — крупный интернет-магазин товаров для животных с широким ассортиментом. Более 20 лет на рынке зоотоваров.

## Проблема

Компания не могла продавать свою продукцию на маркетплейсе OZON. Необходимо было настроить интеграцию по API c маркетплейсом и начать продавать на данной площадке.

## Решение

Команда «Пиксель Плюс» настроила выгрузку товаров для животных в кабинет OZON. Был настроен регулярный обмен остатками и ценами с сайта, обеспечена выгрузку заказов из маркетплейса на сайт.

## Реализация

Сначала провели сопоставление разделов каталога с разделами Ozon.
Каждой категории на сайте была найдена подходящая категория из справочника Ozon.

В каждой из категорий есть свой набор свойств. Свойства, которые обязательные для всех: вес, габариты, бренд, тип товара.

Провели выгрузку значений свойств. Значения почти всех свойств выгружаются из справочников. Справочники Ozon были выгружены на сайт, а затем было сделано сопоставление свойств:

Далее выгрузили на Ozon полностью заполненные товары и провели проверку. Исправили все найденные ошибки.

Загруженные товары создались на Ozon и были отправлены на модерацию.

Модерация на маркетплейсе происходит по следующим критериям:

- Товар на фото соответствует товару в описании (пример: продаёт комплект из 12 банок кошачьего корма. А на фото 1 упаковка - могут не пропустить. Другой пример: Корм для собак 12 кг. А на фото пакет 5 кг).
- Товар имеет правильный коммерческий тип
- Фото хорошего качества, в фокусе, не размыто, без фона, без водяных знаков и надписей
- Точный список ошибок в документации различается для разделов: https://seller-edu.ozon.ru/docs/work-with-goods/kritichnie-oshibki.html

Модерация занимает от 1 до 3 рабочих дней.

Так как работа с маркетплейсом у нас по схеме FBS, мы также настроили регулярную выгрузку остатков и цен с сайта в Ozon. Товары, по которым мы выгрузили остатки, поступили в продажу.

Заказы, которые были оформлены в Ozon, выгружаются на сайт, а далее они уходят в 1С. Заказы из Ozon на сайте носят лишь информационную функцию, на сайте они не обрабатываются.

Подводные камни, с которыми мы столкнулись в процессе работы:

- Проблемы с модерацией товаров.
 Пример: корм для собак разных навесок: 1кг, 3кг, 7кг, 10 кг.
 1кг, 7кг, 10кг - проходят модерацию
 3кг - отклонили

 Повторная модерация занимает время.
- Из одного кабинета нельзя продавать КГТ (крупногабаритные) и не КГТ (не крупногабаритные) товары по схеме FBS.

 Для этого пришлось создать два разных личных кабинета в OZON, настраивать интеграцию в два разных кабинета, а также в двух разных кабинетах обрабатывать заказы.

 Это опять же увеличивает сроки реализации.
- API Ozon не всегда отвечает сразу. Иногда отправляешь запрос на загрузку, а ответ приходит только через сутки.

## Итоги работы

Нам удалось настроить корректную работу магазина с маркетплейсом Ozon по схеме FBS. Но процесс этот оказался не быстрым, так как мы осуществляли интеграцию интернет-магазина с широким ассортиментом и большим количеством разделов.

Такую интеграцию нельзя провести за 1-2 дня. Процесс выгрузки товаров может затянуться из-за особенностей взаимодействия с маркетплейсом, и повлиять на это не возможно.

Тем не менее, работа с Ozon позволила значительно увеличить продажи интернет-магазина magizoo.ru, поэтому оно того стоило.
Мы однозначно рекомендуем всем продавать на маркетплейсах!

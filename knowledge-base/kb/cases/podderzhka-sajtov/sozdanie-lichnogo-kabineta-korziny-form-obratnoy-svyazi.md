# Кейс «Создание личного кабинета, корзины, форм обратной связи» от отдела поддержки компании Пиксель Плюс для сайта ritualservis.org

Поддержка сайтов
Сайт-визитка

Городская ритуальная служба «Броникс-Сервис» 27 лет оказывает ритуальные услуги в Москве и Московской области.

## Проблема

На сайте отсутствовал удобный функционал для оформления заказов и проверки статусов по уже выполненным заказам.

## Решение

Компанией «Пиксель Плюс» в качестве решения изменены карточки товара и каталог, создана корзина в каталоге. Создан личный кабинет. Реализована отправка заявок посредством sms-подтверждения.

## Реализация

1. Проработан каталог для удобства пользователей: товары распределены по разделам, в каждом разделе добавлен фильтр с параметрами для ускорения поиска.

2. Изменена карточка товара:

- добавлена форма обратной связи «Купить в 1 клик»
- добавлен функционал добавления товаров в корзину.

3. На сайт внедрен функционал оформления заказов через Корзину. С нуля создана корзина. Добавлена кнопка «Помощь в оформлении заказа», при нажатии на которую открывается чат в мессенджере Whatsapp для получения консультации.

4. Созданы форма регистрации и форма авторизации на сайте.

5. Реализован личный кабинет со следующими разделами:

- Личные данные
- Контакты
- Заказы
- Корзина

6. На все формы обратной связи дополнительно внедрена авторизация по sms через сторонний сервис sms.ru.

## Итоги работы

Создан процесс удобного и быстрого выбора товаров путем создания каталога с фильтром и корзиной.
Для отслеживания статуса заказов был создан упрощенный личный кабинет на сайте.
Реализован функционал перехода в мессенджеры для получения консультации и помощи в оформлении заказов.

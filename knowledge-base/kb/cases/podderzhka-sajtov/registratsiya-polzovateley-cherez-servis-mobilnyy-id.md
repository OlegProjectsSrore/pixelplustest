# Кейс «Регистрация пользователей через сервис Мобильный ID» от отдела поддержки компании Пиксель Плюс для сайта opt.vilatte.ru

Поддержка сайтов
Интернет-магазин

Компания стремится создавать одежду, которая удовлетворяет основным потребностям покупателей: стильную, из качественных материалов, удобную, хорошо сидящую на фигуре и по комфортным ценам. Для производства одежды используются натуральные материалы. Пошив осуществляется на фабриках России, Узбекистана, Китая, имеющих международный сертификат и применяющих 3-ступенчатую систему контроля качества.

## Проблема

Клиенту требовалось заменить регистрацию/авторизацию с e-mail на SMS-подтверждение.

## Решение

Специалистами «Пиксель Плюс» был сверстан и интегрирован новый макет формы авторизации, интегрирован мобильный id согласно API, реализована система логирования запросов, а также написан скрипт для проверки существующих телефонных номеров на уникальность.

## Реализация

1. Сверстали макет на тестовом сайте
2. Настроили интеграцию мобильного ID по API
3. Написали скрипт для поиска одинаковых телефонных номеров
4. Протестировали доработку и перенесли на боевой сайт

## Итоги работы

Форма авторизации/регистрации работает по номеру телефона.
Возможность авторизоваться по e-mail для пользователей также сохранилась.

# Кейс «Корректировка карточки товара с выводом дополнительных характеристик» от отдела поддержки компании Пиксель Плюс для сайта axpro.expert

## Проблема

Карточка товара содержит неполный список характеристик. Описание выведено сплошным текстом и является неудобным для подбора и сравнения аналогичных товаров между собой.

## Решение

Компанией «Пиксель Плюс» скорректирована верстка карточки товара с добавлением новых характеристик и возможностью форматирования описания.

## Реализация

1. Проанализировали структуру карточки товара
2. Скорректировали описание в виде списка. Добавили множественные свойства для вывода характеристик товара.

## Итоги работы

Реализована новая верстка карточки товаров с выводом дополнительных характеристик, которая является структурированной и удобной для сравнения аналогичных товаров между собой.

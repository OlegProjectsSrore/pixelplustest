# Кейс «Интеграция с СДЭК Фулфилмент» от отдела поддержки компании Пиксель Плюс для сайта myserum.ru

Поддержка сайтов
Лендинг

Проект Myserum.ru - уникальный проект блогера и бьюти эксперта, younger_illusion. Компания разрабатывает индивидуальный протокол домашнего ухода по состоянию кожи, исходя из потребностей клиента и необходимости коррекции проблем (акне, пигментация, розацеа, коррекция возрастных изменений).

## Проблема

В личном кабинете сайта у покупателей отсутствовало корректное отображение статусов заказов.

## Решение

Компанией «Пиксель Плюс» была настроена интеграция с REST API Сдэк Фулфилмент.

## Реализация

1. На сайт установлен готовый модуль «Интеграция со СДЭК» https://marketplace.1c-bitrix.ru/solutions/ipol.sdek/, версии 3.12.7

2. Настроены следующие статусы для отображения в личном кабинете покупателя:

**«Принят»** - проставляется автоматически, после оформления заказа.

**«Оплачен»** - проставляется автоматически, после оплаты.

**«Передан на сборку»** - устанавливается вручную менеджером компании.

При этом, при установке данного статуса будет происходить передача заказа на ФФ.
Данный статус также будет отображаться у покупателей в их личном кабинете, как вы хотели.
Сейчас установлена выгрузка в ФФ по статусу «Передан в сборку».

**«Отправлен»** - устанавливается автоматически после создания накладной СДЭК.

В статусе появляется номер накладной и кнопка «Отследить», при нажатии на которую должна открываться страница отслеживания СДЭК с вбитым номером накладной.
До последней доработки данный статус отображался только в ЛК покупателя, т.е. в разделе администрирования оставался без изменения.
Доработали, чтобы статус менялся и в разделе администрирования.

**«Доставлен»** - устанавливается автоматически при изменении статуса накладной СДЭК на «Доставлен».

До последней доработки данный статус отображался только в ЛК покупателя, т.е. в разделе администрирования оставался без изменения.
Доработали, чтобы статус менялся и в разделе администрирования.

Также с помощью модуля настроено получение номера накладной. Номер накладной кликабельный, при нажатии на номер или на кнопку «Отследить» открывается ссылка на трекинг от СДЭКа вида https://www.cdek.ru/ru/tracking/?order_id=1500209491

## Итоги работы

Налажена передача статусов с сайта и настроено получение статусов с помощью официального модуля СДЭК на сайте.
Сайт получает из ФФ информацию для проставления 2 статусов: «Отправлен» и «Доставлен»
Статус «Передан в сборку» нужен для отправки заказа в ФФ и проставляется вручную менеджером

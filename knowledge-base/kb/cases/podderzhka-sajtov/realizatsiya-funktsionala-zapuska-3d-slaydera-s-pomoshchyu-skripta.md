# Кейс «Реализация функционала запуска 3D слайдера с помощью скрипта» от отдела поддержки компании Пиксель Плюс для сайта axpro.expert

Поддержка сайтов
Лендинг

## Проблема

Слайдер не обладал необходимой конфигурацией для того, чтобы передавать информацию в трехмерном объеме и обеспечивать лучшую визуализацию контента, согласно требованиям заказчика.

## Решение

Компанией «Пиксель Плюс» реализован функционал 3D слайдера с автоматическим перелистыванием изображений.

## Реализация

- Проанализировали CMS клиента на предмет готовых решений
- Внедрили скрипт для автоматической прокрутки слайдера соответствующей конфигурации
- Протестировали

## Итоги работы

Реализован функционал 3D слайдера с автоматическим перелистыванием изображений. Скрипт автоматически запускает прокрутку 3D слайдера.

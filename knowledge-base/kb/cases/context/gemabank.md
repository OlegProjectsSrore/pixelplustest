## Проведённые работы

- Проведен анализ действующих кампаний и конкурентов, на основе которого был выстроен стратегический план работ.
- Разделение семантического ядра по основным видам деятельности компании (забор пуповинной крови, криоконсервация пупочного канатика и выделение стволовых клеток).
- Кампании на Поиск были отделены от РСЯ.
- Гемабанк оказывает услуги по всей РФ, поэтому было принято решение по созданию отдельных кампаний для Москвы и др. крупных городов.
- Полностью переработаны Заголовки и Текста, для максимальной релевантности поисковому запросу и увеличению привлекательности объявлений.
- Переработаны креативы для РСЯ, добавлены широкоформатные изображения.
- Добавлены мобильные объявления и расширения для объявлений.
- Расширен список минус-слов на основе поисковых запросов за время работы кампаний.
- Проставлены UTM-метки.
- На основе статистики Яндекс Метрики были при применены корректировки ставок по полу, возрасту и устройствам.
- Создана отдельная кампания по проведению бесплатных семинаров для беременных для привлечения дополнительной аудитории.

## Итог

- После внесения правок в кампании Яндекс Директ получили результат — увеличение кол-ва звонков более чем в 2 раза.
- Составлен план по работе с кампаниями в Google Ads, для аналогичного улучшения показателей.
- Отслеживание звонков с помощью динамического коллтрекинга дало более полную статистику, какие ключевые слова наиболее конверсионные.

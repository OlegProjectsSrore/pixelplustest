# Кейс по продвижению сайта яблоневого угля через контекстную рекламу в Яндекс Директ

Компания «ГК «Краснинские сады»

Компания «ГК «Краснинские сады» — производитель эксклюзивного экологически чистого яблоневого угля для гриля и мангалов

Начало сотрудничества:

апрель 2021

Основные работы:

Ozon, Яндекс Директ (поиск, РСЯ, ретаргетинг)

Контекстная реклама
Лендинг
Производство

01

Лидогенерация из канала PPC

02

Увеличить трафик на 50%

03

Снизить CPA на 30%

04

Рост онлайн-заявок на 50%

05

Увеличение продаж через Ozon

## Проведённые работы

- Проведен **анализ содержания и визуала карточек товаров на Ozon**, на которые будет генерироваться трафик из Яндекс Директ.
 **Даны рекомендации по корректировке карточек для увеличения конверсии**.
- Проведен **анализ юзабилити сайта** и конкурентов.
- **Установлен счетчик** Яндекс Метрики и настроено отслеживание конверсий.
- **Собрано базовое семантическое ядро**, которое впоследствии расширено при помощи среднечастотных и низкочастотных фраз по опту.
- **Настроены кампании в Яндекс Директ**: поиск, РСЯ, ретаргетинг.
- Ключевые фразы разделены на группы, для каждой из которой **написаны объявления** с использованием преимуществ клиента согласно требованиям Яндекс Директ.
- **Запущены рекламные кампании**, часть с посадочными страницами на сайте, а вторая часть на карточки товаров на Ozon.
- Проведено **A/B-тестирование** объявлений.
- Подобраны **оптимальные стратегии**.
- **Настроены корректировки ставок** по полу, возрасту и на мобильные устройства.
- Собран и запущен в работу **список минус-слов** с обновлением раз в 2-3 дня.
- Регулярно собиралась и анализировалась **статистика с целью определить, какая посадочная страница дает наибольшую
 конверсию по наименьшей цене**.
- **Тестировались** различные группы запросов, креативы и настройки для каждой группы объявлений.

## Результаты проведённых работ

Рост трафика на 80%

CPA снизился на 40%

Рост продаж на Ozon на 100%

Клиент занимается производством и продажей яблочного угля. Перед нами стояла цель увеличить количество заказов через сайт, а также магазин клиента на платформе Ozon. Для этого было принято настроить и запустить рекламные кампании в Яндекс Директ, часть трафика из которых направить на сайт, а часть на Ozon.

Перед стартом юзабилити сайта и конкурентов, а также анализ содержания и визуала карточек товаров на Ozon, составлены рекомендации по корректировке карточек для увеличения конверсии. Для отслеживания взаимодействия пользователей с сайтом и подсчету конверсий, был установлен счетчик Яндекс Метрики и настроены цели.

Запустили кампании в Яндекс Директ на поиске с объемом трафика 75%, РСЯ с объемом трафика 50%, настроили ретаргетинг по правилу «посетил сайт, но не выполнил целевое действие».

В процессе оптимизации рекламных кампаний, отключили неэффективные ключевые фразы, а также весь пул запросов по рознице. Расширили семантическое ядро по тем конверсионным фразам, а также собрали новый пул запросов связанных с оптом. После дополнительного анализа отчета по регионам показа, решили отключить показы в регионах и сконцентрироваться на ЦФО.

Также регулярно собиралась и анализировалась статистика с целью определить, какая посадочная страница дает наибольшую конверсию по наименьшей цене. Тестировались различные группы запросов, креативы и настройки для каждой группы объявлений. После сбора статистики и анализа отключались рекламные кампании, объявления и ключевые запросы с показателями ниже среднего.

Еженедельно добавляли список минус-слов в кампании и на группы объявлений. Повысили объем трафика до 85%. Чтобы сделать акцент на заинтересованных пользователей и снизить % отказов, настроили корректировки по полу, возрасту мобильным устройствам.

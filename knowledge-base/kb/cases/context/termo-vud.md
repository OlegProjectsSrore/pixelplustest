# Кейс по продвижению интернет-магазина производителя продукции из термодревесины в Москве и Подмосковье через контекстную рекламу в Яндекс Директ

«Термо Вуд»

Производство и продажа продукции из термодревесины для внутренней и внешней отделки

май 2019

## Проведённые работы

- Для теста взяли коммерческие запросы (с приставками купить, цена, стоимость) и ВЧ запросы с оператором "кавычки".
- В результате выяснили, что CPL по ключевым словам с коммерческими приставками выше, чем у ВЧ-запросов с оператором "кавычки".
- Для увеличения количества звонков и снижения CPL, было принято решение снизить ставки для групп с коммерческими запросами и повысить для групп с ВЧ-ключами.

## Результаты проведённых работ

Рост онлайн-заявок на 20%

Отказы не выше 11 %

CTR 19,6%

CPC 116 руб

# Кейс по контекстной рекламе в для компании по офсетной печати книг, журналов и газет тиражами

ЗАО «Периодика»

Офсетная печать книг, журналов и газет тиражами

Начало сотрудничества:

июль 2018

Основные работы:

контекстная реклама в Яндекс Директ и Google Ads

Контекстная реклама
Корпоративный сайт

01

Показать быструю отдачу в условиях высокой конкуренции

02

Повысить количество трафика на сайт целевой аудитории

03

Снизить показатель CPL

## Проведённые работы

Шаг 1

- Согласован старт рекламной кампании на поиск для привлечения целевой аудитории с прямым спросом услуги клиента.
- Создана и запущена рекламная кампания на поиск по коммерческим запросам. Подготовлены продающие объявления ориентированные на целевую аудиторию.
- Проработан список минус-слов для исключения не целевого трафика.
- Проведена корректировка ставок согласно анализу аудитории по средствам Яндекс Метрики.
- В силу ограничения бюджета и высокой конкуренции в сфере печати выставлены ставки на охват в 5%.
- Проведен тестовый период работы рекламы. Проведена аналитика показателей и разработана стратегия привлечения аудитории с помощью РСЯ.

Шаг 2

- Для увеличения трафика, а также для увеличения показателя CPL, принято решение создать и запустить рекламу РСЯ.
- Проработаны объявления под целевую аудиторию, подобраны изображения привлекательные для пользователей.
- Проставлены ставки на охват от 50 до 100% в силу низкой стоимости рекламы на РСЯ.
- За основу были взяты как коммерческие запросы, так и запросы общего содержания, близкие к коммерческим. Например, «Где напечатать журналы большим тиражом».
- Выбраны эффективные площадки размещения объявлений, которые приносили конверсию по целям проекта.

Шаг 3

- После получения результатов с РСЯ было принято решение продвигать сайт по средствам РСЯ при этом на низком охвате 5-15% предлагать услугу по прямому спросу.

## Результаты проведённых работ

Трафик увеличился в 8,8 раз

CTR увеличился на 6,58%

CPL снизилось на 50.7%

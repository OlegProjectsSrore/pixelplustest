# Кейс по продвижению сайта по аренде кофемашин для офиса с помощью контекстной рекламы в Яндекс Директ и Google Ads

Veles Grupp LLC

Аренда кофемашин для офисов

Начало сотрудничества:

февраль 2021

Основные работы:

Яндекс Директ (Поиск, РСЯ), Google Ads (Поиск)

Контекстная реклама
Интернет-магазин

01

Получение заявок на аренду кофемашин

02

CTR от 20%

03

Снизить CPC на 10% в процессе работы

04

Снизить отказы до 20%

## Проведённые работы

- Собрана семантика с приставками “для офиса/компаний”, а также семантика с упоминанием брендов кофемашин, например “аренда кофемашин jura / delonghi”.
- Семантика разбита на группы.
- Для каждой группы написаны объявления с вхождением ключевых запросов в заголовок.
- Настроены цели в Яндекс Метрике для отслеживания конверсий.
- В ссылки добавлены UTM-метки.
- Запущены 3 кампании — Поиск (Яндекс Директ и Google Ads) и РСЯ (Яндекс Директ).
- В процессе показа объявлений собрана аудитория тех, кто скачивал КП с сайта (по условию скачали КП / не отправили заявку). На данную аудиторию запущен ретаргетинг.
- Через Яндекс Аудитории создан ГЕО сегмент (полигон) по ЦА, которая работает в Москва-Сити. На нее добавлена повышающая корректировка ставок.
- В процессе работы проводился анализ поисковых запросов, добавление НЧ-запросов, добавление минус-слов, анализ и отключение площадок показов в РСЯ, А/В тестирование объявлений, работа со ставками и стратегиями.

## Результаты проведённых работ

Увеличение CTR на 39%

Снижение отказов в 2 раза

Конверсия из поиска 7,7 %

Конверсия из РСЯ 1,2 %

Снижение CPC на 15%

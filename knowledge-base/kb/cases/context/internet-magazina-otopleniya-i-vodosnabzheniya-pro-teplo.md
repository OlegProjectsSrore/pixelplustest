# Кейс по настройке стратегий в Яндекс Маркет через PriceLabs для интернет-магазина отопления и водоснабжения Pro Teplo

Интернет-магазина отопления и водоснабжения Pro Teplo

Продажа и монтаж оборудования для отопления, водоснабжения и канализации в Санкт-Петербурге

## Проведённые работы

- Товары разделены по категориям и маржинальности.
- Для каждой категории созданы группы в PriceLabs.
- На основе данных о маржинальности (более/менее 1000 руб.), установлена стратегия по CPO.
- На товары с большей маржинальностью установлен приоритет показов.

## Результаты проведённых работ

CPL менее 1 000 рублей

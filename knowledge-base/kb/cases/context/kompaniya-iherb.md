## Проведённые работы

- Выбраны и согласованы приложения для показов.
- Приложения разделены на группы для iOS и Android.
- В соответствии с требованиями Google Ads созданы баннеры.
- Для каждого приложения созданы отдельные группы объявлений.

## Результаты проведённых работ

Снижение CPC на 66%

Увеличение кол-ва кликов в 2 раза

Увеличение охвата за счет добавления новый приложений

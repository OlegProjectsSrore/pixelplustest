## Проведённые работы

- Проведен анализ действующих рекламных кампаний, на основе которого был выстроен стратегический план работ.
- Проведено расширение семантики по направлению коммерческих запросов, по маркам автомобилей, по бренду АКБ (аккумуляторно кислотная батарея).
- К каждой группе добавлены мобильные объявления, а на кампании добавлены дополнительные расширения (визитки, отображаемые ссылки, уточнения, быстрые ссылки).
- Для групп объявлений подобраны релевантные посадочные страницы.
- Внесены правки в тексты объявлений рекламных кампаний на поиске.
- Подготовлена видео реклама, заменены креативы в графических объявлениях и изображения в текстово-графических изображениях.
- Подключен сервис сквозной аналитики Calltouch и интегрированы средства аналитики с данным сервисом.
- В действующих рекламных кампаниях проставлены UTM-метки, для более корректной передачи информации в сервис отслеживания звонков.
- За тестовый период был проведен анализ количества телефонных обращений в компанию, время обращений (по времени суток), определены самые конверсионные типы рекламных кампаний, определены самые конверсионные ключевые фразы.
- На основе анализа телефонных обращений по времени суток, было принято решение в действующих рекламных кампаниях ограничить время показов объявлений в соответствии с режимом работы офлайн точек. Так как статистика показала, что пользователь не перезванивает повторно, а телефонные номера не сохраняются, конверсий по оформлению заявок практически нет.
- Со стороны бизнеса было принято решение о внедрении АТС, для отслеживания звонков вне рабочее время.
- Собран широкий список минус-слов для Яндекс Директ и Google Ads., поставлено задание специалисту на еженедельную минусацию нецелевых ключевых запросов. Также проведена корректная кросс-минусация ключевых фраз.
- Проведена объемная работа по корректной установке типов соответствия ключевых фраз в Google Ads.
- Создана ретаргетинговая рекламная кампания с широкими и более детальными условиями подбора аудитории.
- Согласно статистике Яндекс Метрики и Calltouch, был проведен перерасчет дневных бюджетов по рекламным кампаниям для более эффективного распределения средств.
- Предоставлены рекомендации по правкам на сайте для увеличения привлекательности сайта для пользователей и увеличения конверсий в лиды.
- Проведен анализ действующих околоцелевых запросов, на предмет наличия по ним конверсий. По результатам проведена работа по сокращению ставки или полного отключения неэффективных запросов.
- Проработаны корректировки ставок по полу, возрасту и устройствам.
- Для Яндекс Маркета был подключен бид-менеджер Price Labs, проведены настройки стратегий.

## Итог

- Правка по рекламе дала должный результат, был сделан основной акцент на Яндекс Директ и отработан на данной стадии по максимуму.
- Составлен план по работе с Google Ads., для улучшения показателей.
- Внедрение сквозной аналитики позволило корректно рассчитывать CPL (стоимость лида), что в свою очередь позволило вести рекламу более продуктивно, увеличивать бюджет, в целях большего оборота бизнеса, при сохранении данного показателя на согласованном уровне или ниже данного порога.
